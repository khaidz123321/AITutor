# 6.6.2.3. Phân loại các mặt bậc hai

Trong hệ tọa độ Descartes vuông góc Oxyz xét mặt $(Q)$ bậc hai có phương trình:

$a_{11} x^2 + a_{22} y^2 + a_{33} z^2 + 2a_{12} xy + 2a_{13} xz + 2a_{23} yz + 2b_1 x + 2b_2 y + 2b_3 z + c = 0.$ (6.72)

Xét dạng toàn phương

$$
Q(x, y, z) = a_{11} x^2 + a_{22} y^2 + a_{33} z^2 + 2a_{12} xy + 2a_{13} xz + 2a_{23} yz.
$$

Mà rank chính tắc của ma trận $A = \left[ a_{ij} \right]_{i,j=1,3}$ với $a_{ij} = a_{ji}$ là ma trận đối xứng nên tồn tại ma trận trực giao $T$ sao cho 

$$
T^t A T = \begin{bmatrix}
\lambda_1 & 0 & 0 \\
0 & \lambda_2 & 0 \\
0 & 0 & \lambda_3 
\end{bmatrix}.
$$

Có thể chọn $T$ thỏa mãn $\det(T) = 1$ (để hệ trục tọa độ tạo thành tam diện thuận).

Tương tự với ma trận chuyển cơ số $T$ là chọn hệ trục tọa độ mới bằng cách quay quanh gốc tọa độ.

$$
\begin{array}{c} \mathrm { C }\hat{\mathrm{o}}\mathrm{n}\mathrm{g} \mathrm{t}\check{\mathrm{h}}\mathrm{u}\mathrm{c} \mathrm{d}\hat{\mathrm{o}}\mathrm{i} \mathrm{t}\hat{\mathrm{o}}\mathrm{a}\hat{\mathrm{d}} \\ { \mathrm{C }\hat{\mathrm{o}}\mathrm{n}\mathrm{g} \mathrm{t}\check{\mathrm{h}}\mathrm{u}\mathrm{c} \mathrm{d}\hat{\mathrm{o}}\dot{1} \mathrm{t}\hat{\mathrm{o}}\mathrm{a}\hat{\mathrm{d}}} \\ { \mathrm{~\Omega ~ } \qquad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad } \\ { \mathrm{ \Omega } } \end{array} \left[ \begin{array}{l} x \\ y \\ z \end{array} \right] = T \left[ \begin{array}{l} x ^{\prime} \\ y ^{\prime} \\ z ^{\prime} \end{array} \right].
$$

Mặt bậc 2 $(Q)$ có phương trình trong hệ trục tọa độ mới:

$$
\lambda _ { 1 } { x ^ { \prime } } ^ { 2 } + \lambda _ { 2 } { y ^ { \prime } } ^ { 2 } + \lambda _ { 3 } { z ^ { \prime } } ^ { 2 } + 2 { b ^ { \prime } } _ { 1 } x ^ { \prime } + 2 { b ^ { \prime } } _ { 2 } y ^ { \prime } + 2 { b ^ { \prime } } _ { 3 } z ^ { \prime } + c = 0.
$$

Tuy theo các giá trị của $\lambda _ { 1 } , \lambda _ { 2 } , \lambda _ { 3 } , \boldsymbol { b } _ { 1 } ^ { \prime } , \boldsymbol { b } _ { 2 } ^ { \prime } , \boldsymbol { b } _ { 3 } ^ { \prime } , \boldsymbol { c }$, mặt $( Q )$ có các dạng sau:

a) Các giá trị riêng $\lambda _ { 1 } , \lambda _ { 2 } , \lambda _ { 3 }$ khác $0 (\lambda_{22} \neq 0)$

Bằng cách tiến hành tọa độ trục ta có thể đưa phương trình (6.73) về dạng:

$$
\lambda _ { 1 } X ^ { 2 } + \lambda _ { 2 } Y ^ { 2 } + \lambda _ { 3 } Z ^ { 2 } = C ^ { \prime } .
$$

*) Nếu $C ^ { \prime } \neq 0$:

- $\lambda _ { 1 } , \lambda _ { 2 } , \lambda _ { 3 } , C ^ { \prime }$ cùng dấu: $( Q )$ là elipsoit;
- $\lambda _ { 1 } , \lambda _ { 2 } , \lambda _ { 3 }$ cùng dấu, $C ^ { \prime }$ trái dấu: $( Q )$ là elipsoit ảo;
- $\lambda _ { 1 } , \lambda _ { 2 } , \lambda _ { 3 }$ chỉ có hai số cùng dấu: $( Q )$ là hypeboloid một tảng hoặc hai tảng.

*) Nếu $C ^ { \prime } = 0$:

- $\lambda _ { 1 } , \lambda _ { 2 } , \lambda _ { 3 }$ chỉ có hai số cùng dấu: $( Q )$ là nón bậc 2.
- $\lambda _ { 1 } , \lambda _ { 2 } , \lambda _ { 3 }$ cùng dấu: $( Q )$ là nón ảo (một điểm).

Các trường hợp còn lại sau đây ta chỉ xét mỗi trường hợp một loại đại diện, các loại khác có kết quả tương tự.

b) Có dùng một giá trị trong ba giá trị $\lambda_{1}, \lambda_{2}, \lambda_{3}$ bằng 0:

Chẳng hạn $\lambda_{3} = 0, \lambda_{1} \lambda_{2} \neq 0$:

*) $b'_{3} \neq 0$: Tính tiếp hệ tọa độ ta được: $\lambda_{1} X^{2} + \lambda_{2} Y^{2} + 2 b'_{3} Z = 0$

Đây là phương trình Paraboloid elip nếu $\lambda_{1} \lambda_{2} > 0$ và Paraboloid hyperbol nếu $\lambda_{1} \lambda_{2} < 0$:

*) $b'_{3} = 0$: Tính tiếp tọa độ ta được: $\lambda_{1} X^{2} + \lambda_{2} Y^{2} = C'$

·Nếu $C' \neq 0$: Đây là phương trình các mặt trụ.
·Nếu $C' = 0$: Đây là phương trình các cặp mặt phẳng cắt nhau hoặc trục ($2Z' Z$):

c) Có dùng hai giá trị trong ba giá trị $\lambda_{1}, \lambda_{2}, \lambda_{3}$ bằng 0.

Chẳng hạn $\lambda_{3} = 0, \lambda_{2} = 0, \lambda_{1} \neq 0$: $\delta_{b'_{2}, b'_{3}}$ không đồng thời bằng 0.

Bằng cách quay hệ trục tọa độ

$$
\left\{ \begin{array} { l } { x _ { 1 } ^ { \prime } = x _ { 1 } ^ { " } } \\ { x _ { 2 } ^ { \prime } = \frac { b _ { 3 } ^ { \prime } x _ { 2 } ^ { " } } { \sqrt { { b _ { 2 } ^ { \prime } } ^ { 2 } + { b _ { 3 } ^ { \prime } } ^ { 2 } } } + \frac { b _ { 2 } ^ { \prime } x _ { 3 } ^ { " } } { \sqrt { { b _ { 2 } ^ { \prime } } ^ { 2 } + { b _ { 3 } ^ { \prime } } ^ { 2 } } } } \\ { x _ { 3 } ^ { \prime } = - \frac { b _ { 2 } ^ { \prime } x _ { 2 } ^ { " } } { \sqrt { { b _ { 2 } ^ { \prime } } ^ { 2 } + { b _ { 3 } ^ { \prime } } ^ { 2 } } } + \frac { b _ { 3 } ^ { \prime } x _ { 3 } ^ { " } } { \sqrt { { b _ { 2 } ^ { \prime } } ^ { 2 } + { b _ { 3 } ^ { \prime } } ^ { 2 } } } } \end{array} \right. .
$$

Phương trình trên trở thành

$$
\lambda _ { 1 } \left( x " _ { 1 } + \frac { b " _ { 1 } } { \lambda _ { 1 } } \right) ^ { 2 } + 2 \sqrt { { b " _ { 2 } } ^ { 2 } + { b " _ { 3 } } ^ { 2 } } x " _ { 3 } + c - \frac { { b " _ { 1 } } ^ { 2 } } { \lambda _ { 1 } } = 0 .
$$

Thực hiện tính tien trục toạ độ $\hat{\mathbf{d}}\hat{\mathbf{0}}$ ta được phương trình dạng:

$$
\lambda _ { 1 } X ^ { 2 } + b " _ { 2 } Y = 0 : ( Q ) \text{ là đường parabol. }
$$

$ b _ { 2 } ^ { \prime } = b _ { 3 } ^ { \prime } = 0 $: Tính tiến hệ tọa độ $\hat{\mathbf{d}}\hat{\boldsymbol{0}}$ ta có: $\lambda _ { 1 } X ^ { 2 } = C ^ { \prime }$. Do đó (6.72) là phương trình cặp mặt phẳng song song nếu $C ^ { \prime } \neq 0$ và trùng nhau nếu $C ^ { \prime } = 0$:

Ví dụ 6.26: Trong không gian với hệ tọa độ Oxyz cho mặt bậc hai có phương trình

$$
( Q ) : 7 x ^ { 2 } + 7 y ^ { 2 } + 10 z ^ { 2 } + 2 x y + 4 x z + 4 y z - 12 x + 12 y + 72 z = 24.
$$

Ma trận của dạng toàn phương tương ứng $A = \left[ \begin{array} { l l l } { 7 } & { 1 } & { 2 } \\ { 1 } & { 7 } & { 2 } \\ { 2 } & { 2 } & { 10 } \end{array} \right] .$

Đa thức đặc trưng: $\left| A - \lambda I \right| = (6 - \lambda)^{2}(12 - \lambda)$

Tìm cơ sở của các không gian riêng và thực hiện chuẩn hóa Gram-Schmidt ta có ma trận trực góc

$$
T = \left[ \begin{array} { l l l } { - 1 / \sqrt{2} } & { - 1 / \sqrt{3} } & { 1 / \sqrt{6} } \\ { 1 / \sqrt{2} } & { - 1 / \sqrt{3} } & { 1 / \sqrt{6} } \\ { 0 } & { 1 / \sqrt{3} } & { 2 / \sqrt{6} } \end{array} \right] \text{ với } \operatorname*{det} T = 1 \text{ và } T ^ { t } A T = \left[ \begin{array} { l l l } { 6 } & { 0 } & { 0 } \\ { 0 } & { 6 } & { 0 } \\ { 0 } & { 0 } & { 12 } \end{array} \right] .$$

$$
\begin{array} { c } { 6 { x ^ { \prime } } ^ { 2 } + 6 { y ^ { \prime } } ^ { 2 } + 12 { z ^ { \prime } } ^ { 2 } - 12 \left( - \frac { 1 } { \sqrt { 2 } } x ^ { * } - \frac { 1 } { \sqrt { 3 } } y ^ { * } + \frac { 1 } { \sqrt { 6 } } z ^ { \prime } \right) } \\ { + 12 \left( \frac { 1 } { \sqrt { 2 } } x ^ { * } - \frac { 1 } { \sqrt { 3 } } y ^ { * } - \frac { 1 } { \sqrt { 6 } } z ^ { \prime } \right) + 72 \left( \frac { 1 } { \sqrt { 3 } } y ^ { * } + \frac { 2 } { \sqrt { 6 } } z ^ { \prime } \right) = 24 }
\end{array} .
$$

$$
\Rightarrow 6 \left( x ^ { \prime } ^ { 2 } + 2 \sqrt { 2 } x ^ { \prime } \right) + 6 \left( y ^ { \prime } ^ { 2 } + 4 \sqrt { 3 } y ^ { \prime } \right) + 12 \left( z ^ { \prime } ^ { 2 } + 2 \sqrt { 6 } z ^ { \prime } \right) = 24 .
$$

Tính tiến tọa độ: $X = x ^ { \prime } + \sqrt { 2 } , Y = y ^ { \prime } + 2 \sqrt { 3 } , Z = z ^ { \prime } + \sqrt { 6 }$. Suy ra:

$$
( Q ) \colon \frac { X ^ { 2 } } { 30 } + \frac { Y ^ { 2 } } { 30 } + \frac { Z ^ { 2 } } { 15 } = 1 .
$$

Vậy $( Q )$ là một elipsoit tròn xoay theo trục $Z ^ { \prime } \Omega Z$:

$$
\Omega ( - \sqrt { 2 } , - 2 \sqrt { 3 } , - \sqrt { 6 } ).
$$

Ví dụ 6.27: Trong không gian với hệ tọa độ Oxyz cho mặt bậc 2 có phương trình

$(Q) : 2xy + 2xz + 2yz - 6x - 6y + 6z = 0.$

Ma trận của dạng toán phương tương ứng $A = \left[ \begin{array} { l l l } { 0 } & { 1 } & { 1 } \\ { 1 } & { 0 } & { 1 } \\ { 1 } & { 1 } & { 0 } \end{array} \right] .$

Đa thức đặc trưng: $\big | A - \lambda I \big | = (\lambda + 1)^2 (2 - \lambda)$:

Tìm cơ sở của các không gian riêng và trực chuẩn hóa Gram-Schmidt ta có ma trận trực góc

$$
T = \left[ { \frac{-1 / \sqrt{2}}{1 / \sqrt{2}} } \quad -\frac{1}{\sqrt{6}} \quad \frac{1}{\sqrt{3}} \right] \text{ với } \det T = 1 \text{ và } T^t A T = \left[ { \begin{array} { c c c } { -1 } & { 0 } & { 0 } \\ { 0 } & { -1 } & { 0 } \\ { 0 } & { 0 } & { 2 } \end{array} } \right] .
$$

$$
\begin{array} { c } { - x^{\prime 2} - y^{\prime 2} + 2 z^{\prime 2} - 6 e \left( - \frac { 1 } { \sqrt { 2 } } x^{\prime} - \frac { 1 } { \sqrt { 6 } } y^{\prime} + \frac { 1 } { \sqrt { 3 } } z^{\prime} \right) } \\ { - 6 e \left( \frac { 1 } { \sqrt { 2 } } x^{\prime} - \frac { 1 } { \sqrt { 6 } } y^{\prime} + \frac { 1 } { \sqrt { 3 } } z^{\prime} \right) + 6 e \left( \frac { 2 } { \sqrt { 6 } } y^{\prime} + \frac { 1 } { \sqrt { 3 } } z^{\prime} \right) = 0 . }
\end{array}
$$

Tính tọa độ: $X = x^{\prime}, Y = y^{\prime} - 2 \sqrt {6}, Z = z^{\prime} - \frac {\sqrt {3}} {2}.$ Suy ra

$$
( Q ) \colon \frac { 2 X ^ { 2 } } { 45 } + \frac { 2 Y ^ { 2 } } { 45 } - \frac { 4 Z ^ { 2 } } { 45 } = 1.
$$

Vậy $( Q )$ là mặt Hyperboloid một tấm.
