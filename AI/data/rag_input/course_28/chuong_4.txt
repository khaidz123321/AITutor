# 4.1. KHAI NIỆM HỆ PHƯƠNG TRÌNH TUYẾN TÍNH

Trong không gian với hệ trục tọa độ Oxyz, tập hợp các điểm có tọa độ $(x, y, z)$ thỏa mãn phương trình $Ax + By + Cz = D$ là một mặt phẳng.

Do đó tập hợp nghiệm của hệ phương trình $\left\{ \begin{array}{l} A_1 x + B_1 y + C_1 z = D_1 \\ A_2 x + B_2 y + C_2 z = D_2 \end{array} \right.$ là giao của hai mặt phẳng, vì vậy hệ phương trình có thể vô nghiệm hoặc hữu số nghiệm.

Tương tự tập hợp nghiệm của hệ phương trình $\left\{ \begin{array} { l l } { A _ { 1 } x + B _ { 1 } y + C _ { 1 } z = D _ { 1 } } \\ { A _ { 2 } x + B _ { 2 } y + C _ { 2 } z = D _ { 2 } } \\ { A _ { 3 } x + B _ { 3 } y + C _ { 3 } z = D _ { 3 } } \end{array} \right.$ là giao của ba mặt phẳng, vì vậy hệ phương trình có thể vô nghiệm hoặc duy nhất nghiệm hoặc vô số nghiệm.

Khái niệm hệ phương trình tuyến tính tổng quát và phương pháp giải được xét trong các mục sau.

# 4.1.1. Đạng tổng quát của hệ phương trình tuyến tính

Hệ m phương trình tuyến tính n ẩn có dạng tổng quát:

$$
{ \left\{ \begin{array} { l } { a _ { 1 1 } x _ { 1 } + a _ { 1 2 } x _ { 2 } + . . . + a _ { 1 n } x _ { n } = b _ { 1 } } \\ { a _ { 2 1 } x _ { 1 } + a _ { 2 2 } x _ { 2 } + . . . + a _ { 2 n } x _ { n } = b _ { 2 } } \\ { . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . .

Nghiệm của hệ phương trình là bao gồm $n$ số $\left( x _ { 1 } , x _ { 2 } , . . . , x _ { n } \right)$ sao cho khi thay vào (4.1) ta có các đẳng thức đúng. Giải một hệ phương trình là đi tìm tập hợp nghiệm của hệ.

Hai hệ phương trình cùng dạng là tương đương nếu tập hợp nghiệm của chúng bằng nhau. Vì vậy để giải một hệ phương trình ta có thể giải hệ phương trình tương đương của nó.

# 4.1.2. Đạng ma trận của hệ phương trình tuyến tính

Với hệ (4.1) ta xét các ma trận:

$$
A = \left[ \begin{array} { l l l l } a _ { 1 1 } & a _ { 1 2 } & \ldots & a _ { 1 n } \\ a _ { 2 1 } & a _ { 2 2 } & \ldots & a _ { 2 n } \\ \vdots & \vdots & \ddots & \vdots \\ a _ { m 1 } & a _ { m 2 } & \ldots & a _ { m n } \end{array} \right] , B = \left[ \begin{array} { l } b _ { 1 } \\ b _ { 2 } \\ \vdots \\ b _ { m } \end{array} \right] , X = \left[ \begin{array} { l } x _ { 1 } \\ x _ { 2 } \\ \vdots \\ x _ { n } \end{array} \right] .
$$

$A, B, X$ lần lượt được gọi là ma trận hệ số, ma trận vế phải và ma trận nghiệm. Khi đó hệ phương trình (4.1) được viết lại dưới dạng ma trận:

$$
A X = B.
$$

Trong trường hợp $A$ khả nghịch thì hệ phương trình có nghiệm $X = A ^ { - 1 } B$.

# 4.1.3. Đạng véc tơ của hệ phương trình tuyến tính

Nếu ta ký hiệu vector cột thứ $i$ của ma trận $A$ là $\nu_i = (a_{1i}, . . . , a_{mi}) \in \mathbb{R}^m$ và vector sau $b = (b_1, . . . , b_m) \in \mathbb{R}^m$, thì hệ (4.1) được viết dưới dạng vector:

$$
x_1\nu_1 + x_2\nu_2 + . . . + x_n\nu_n = b.
$$

(4.4)

Với cách viết này ta thấy rằng hệ phương trình (4.1) có nghiệm khi và chỉ khi $b \in \operatorname{span}\{\nu_1, . . . , \nu_n\}.$

Ví dụ 4.1: Xét hệ phương trình viết dưới dạng tổng quát:

$$
\left\{
\begin{array}{ll}
2x_1 + 2x_2 - x_3 + x_4 = 4 \\
4x_1 + 3x_2 - x_3 + 2x_4 = 6 \\
8x_1 + 5x_2 - 3x_3 + 4x_4 = 12
\end{array}
\right.
$$

Hệ phương trình viết dưới dạng ma trận như sau:

$$
{ \left[ \begin{array} { l l l l } { 2 } & { 2 } & { - 1 } & { 1 } \\ { 4 } & { 3 } & { - 1 } & { 2 } \\ { 8 } & { 5 } & { - 3 } & { 4 } \end{array} \right] } { \left[ \begin{array} { l } { x _ { 1 } } \\ { x _ { 2 } } \\ { x _ { 3 } } \\ { x _ { 4 } } \end{array} \right] } = { \left[ \begin{array} { l } { 4 } \\ { 6 } \\ { 12 } \end{array} \right] }
$$

Xét các vector:

$$
\nu _ { 1 } = ( 2 , 4 , 8 ) , \nu _ { 2 } = ( 2 , 3 , 5 ) , \nu _ { 3 } = ( - 1 , - 1 , - 3 ) , \nu _ { 4 } = ( 1 , 2 , 4 ) ; b = ( 4 , 6 , 12 ).
$$

Khi đổi hệ phương trình trên có thể viết dưới dạng vector:

$$
x _ { 1 } ( 2 , 4 , 8 ) + x _ { 2 } ( 2 , 3 , 5 ) + x _ { 3 } ( - 1 , - 1 , - 3 ) + x _ { 4 } ( 1 , 2 , 4 ) = ( 4 , 6 , 12 ).
$$

# 4.2. ĐỊNH LÝ TỒN TẠI Nghiệm

Định lý 4.1: (Kronecker-Capelli) Hệ phương trình (4.1) có nghiệm khi và chỉ khi $r(A) = r(\tilde{A})$ trong đó $\tilde{A}$ là ma trận được tạo bằng cách bổ sung thêm vào ma trận hệ số $A$ một cột cuối cùng là vector phải của hệ phương trình.

$$
r(A) = r(\tilde{A}); \quad \tilde{A} = \left[ \begin{array}{cccc}
a_{11} & \ldots & a_{1n} & b_1 \\
\vdots & \ddots & \vdots & \vdots \\
a_{m1} & \ldots & a_{mn} & b_m
\end{array} \right].
$$

Chứng minh: Hệ (4.1) có nghiệm khi và chỉ khi tồn tại $x_1, x_2, \ldots, x_n \in \mathbb{R}^n$ sao cho $x_1\nu_1 + x_2\nu_2 + \ldots + x_n\nu_n = b$. Nghĩa là $b \in \operatorname{span}\{\nu_1, \ldots, \nu_n\}$ ($b$ biểu diễn được thành hợp thức tuyến của $\{\nu_1, \ldots, \nu_n\}$). Vì vậy $r(\nu_1, \ldots, \nu_n) = r(\nu_1, \ldots, \nu_n, b)$. Do đó $r(A) = r(\tilde{A})$.

Vi dụ 4.2: $\mathsf { H } \hat{\mathsf { e }}$ phương trình trong ví dụ 4.1 có ma trận hệ số $A = \left[ \begin{array}{llll}
2 & 2 & -1 & 1 \\
4 & 3 & -1 & 2 \\
8 & 5 & -3 & 4
\end{array} \right] ,$ ma trận bổ sung cột cuối $\widetilde{A} = \left[ \begin{array}{lllll}
2 & 2 & -1 & 1 & 4 \\
4 & 3 & -1 & 2 & 6 \\
8 & 5 & -3 & 4 & 12
\end{array} \right] .$

Hàng $r(A) = r(\widetilde{A}) = 3$, do đó hệ phương trình có nghiệm.

# 4.3. PHƯƠNG PHÁP CRAMER

## 4.3.1. Hệ Cramer và cách giải

Định nghĩa 4.2: Hệ phương trình tuyến tính với số phương trình bằng số ẩn và định thức của ma trận hệ số khác 0 được gọi là hệ Cramer.

Định lý 4.2: Mọi hệ Cramer đều tồn tại duy nhất nghiệm.

Cụ thể, hệ $\sum_{j=1}^{n} a_{ij} x_j = b_i , \ i = 1, ..., n$ có công thức nghiệm $x_i = \frac{D_i}{D}, \ i = 1, ..., n ;$ trong đó 
\[
D = \operatorname*{det} A = D_{\mathcal {B}} \left\{\nu_1 , . . . , \nu_{i-1} , \nu_i , \nu_{i+1} , . . . , \nu_n \right\},
\]
\[
D_i = D_{\mathcal {B}} \left\{ \nu_1, . . . , \nu_{i-1}, b, \nu_{i+1}, . . . , \nu_n \right\}.
\]

$D_{i}$ là định nghĩa của determinant khi các vector cột là các vector hệ số của hệ phương trình, nhưng vector cột thứ $i$ được thay thế bằng vector cột $b$.

Chứng minh: det $A \neq 0 \implies \left\{ \nu _ { 1 } , . . . , \nu _ { n } \right\}$ là một cơ sở của $\mathbb { R } ^ { n }$. Do đó, $b$ được biểu diễn duy nhất thành hợp tuyến tính của $\left\{ \nu _ { 1 } , . . . , \nu _ { n } \right\}$. Nghĩa là tồn tại duy nhất $(x _ { 1 } , x _ { 2 } , . . . , x _ { n })$ sao cho $x _ { 1 } \nu _ { 1 } + x _ { 2 } \nu _ { 2 } + . . . + x _ { n } \nu _ { n } = b$:

Gọi $\mathcal{B} = \left\{ e _ { 1 } , . . . , e _ { n } \right\}$ là cơ sở chính tắc của $\mathbb { R } ^ { n }$. Khi đó:

$$
D_{i} = D_{\mathcal{B}} \left\{ \nu _ { 1 } , . . . , \nu _ { i - 1 } , b, \nu _ { i + 1 } , . . . , \nu _ { n } \right\} = D_{\mathcal{B}} \left\{ \nu _ { 1 } , . . . , \nu _ { i - 1 } , \sum _ { k = 1 } ^ { n } x _ { k } \nu _ { k }, \nu _ { i + 1 } , . . . , \nu _ { n } \right\}
$$

$$
= x_{i} D_{\mathcal{B}} \left\{ \nu _ { 1 } , . . . , \nu _ { i - 1 } , \nu _ { i }, \nu _ { i + 1 } , . . . , \nu _ { n } \right\} = x_{i} D \Rightarrow x_{i} = \frac{D_{i}}{D}, i = 1, . . . , n.
$$

Vi dụ 4.3: Hệ phương trình 
\[
\left\{ \begin{array} { r c c c c c c c } 
{ 2x } & { + } & { 3y } & { - } & { z } & { = } & { 1 } \\ 
{ 3x } & { + } & { 5y } & { + } & { 2z } & { = } & { 8 } \\ 
{ x } & { - } & { 2y } & { - } & { 3z } & { = } & { -1 } 
\end{array} \right. 
\]
$D = \left| { \begin{array} { c c c } 
{ 2 } & { 3 } & { -1 } \\ 
{ 3 } & { 5 } & { 2 } \\ 
{ 1 } & { -2 } & { -3 } 
\end{array} } \right| = 22, D_x = \left| { \begin{array} { c c c } 
{ 1 } & { 3 } & { -1 } \\ 
{ 8 } & { 5 } & { 2 } \\ 
{ -1 } & { -2 } & { -3 } 
\end{array} } \right| = 66,$

$$
D_y = \left| \begin{array} { c c c } 
{ 2 } & { 1 } & { -1 } \\ 
{ 3 } & { 8 } & { 2 } \\ 
{ 1 } & { -1 } & { -3 } 
\end{array} \right| = -22, D_z = \left| \begin{array} { c c c } 
{ 2 } & { 3 } & { 1 } \\ 
{ 3 } & { 5 } & { 8 } \\ 
{ 1 } & { -2 } & { -1 }

$$

Do đó hệ có nghiệm $x = 3, y = -1, z = 2$

# 4.5. GIẢI HỆ PHƯƠNG TRÌNH TUYẾN TÍNH BẰNG PHƯƠNG PHÁP KHU GAUSS

Ta có thể kiểm tra được rằng: khi thực hiện các biến đổi tương đương sau lên các phương trình của hệ thức sẽ được hệ mới tương đương:

· Đổi hai phương trình;  
· Nhân, chia một số khác 0 vào cả hai vế của một phương trình;   
· Cộng vào một phương trình một tổ hợp tuyến tính các phương trình khác.

Giải hệ phương trình tuyến tính bằng phương pháp khử Gauss là thực hiện các phép biến đổi trong tương đương (có thể đổi chỉ số các biến) để đưa hệ phương trình (4.1)

$$
\sum _ { j = 1 } ^ { n } a _ { i j } x _ { j } = b _ { i } ; \quad i = 1 , . . . , m .
$$

về hệ tương đương

$$
\sum _ { j = 1 } ^ { n } a _ { i j } ^ { \prime } x _ { j } ^ { \prime } = b _ { i } ^ { \prime } ; \quad i = 1 , . . . , m .
$$

Các biến $x _ { 1 } ^ { \prime } , . . . , x _ { n } ^ { \prime }$ là các biến $x _ { 1 } , . . . , x _ { n }$ nhưng có thể thay đổi thứ tự chỉ số và ma trận bổ sung của hệ mới có dạng

$$
