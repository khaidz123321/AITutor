# 6.6.1.3. Phân loại đường bậc 2 trong mặt phẳng

Trong mặt phẳng cho hệ tọa độ $\hat{\mathrm{d}}\hat{\mathrm{o}}$ Descartes vuông góc Oxy. Một đường cong bậc 2 có phương trình tổng quát:

$$
a_{11} x^2 + 2 a_{12} xy + a_{22} y^2 + 2 a_1 x + 2 a_2 y + a_0 = 0,
$$

trong đó $a_{11}$, $a_{12}$, $a_{22}$ không đồng thời bằng không.

Ta tìm mặt hệ tọa độ Descartes vuông góc mới $\mathsf{d}\acute{\mathrm{e}}$ trong $\mathrm{h}\hat{\mathrm{e}}$ tọa $\hat{\mathbf{d}}\hat{\mathbf{\rho}}$ này đường cong (6.68) có dạng chính tắc.

$$
\mathrm{Xét} \mathrm{mặt} \mathrm{hàn} \acute{\mathrm{d}} \mathrm{o} \mathrm{i} \mathrm{x} \acute{\mathrm{u}ng} A = \left[ {a}_{11} \quad {a}_{12} \right], \ a_{12} = {a}_{21}.
$$

Ma trận $A$ đối xứng nên chéo hóa trục giao điểm, nghĩa là tồn tại ma trận chuyển giao $T$ sao cho:

$$
\operatorname{det} T = 1 \quad \text{và} \quad T^t A T = \left[ { \begin{array}{cc}
\lambda_1 & 0 \\
0 & \lambda_2 
\end{array}} \right].
$$

$$
T = \left[ \cos \varphi \quad -\sin \varphi \\ \sin \varphi \quad \cos \varphi \right] .
$$

Công thức đổi tọa độ

$$
{ \left[ \begin{array} { l } { x } \\ { y } \end{array} \right] } = { \left[ \begin{array} { l l } { \cos \varphi } & { - \sin \varphi } \\ { \sin \varphi } & { \cos \varphi } \end{array} \right] } { \left[ \begin{array} { l } { x ^ { \prime } } \\ { y ^ { \prime } } \end{array} \right] } .
$$

Như vậy hệ tọa độ mới $Ox'y'$ được bằng cách quay hệ tọa độ $Oxy$ quanh gốc O một góc $\varphi$:

Phương trình đường bậc 2 có công thức (6.68) trong hệ tọa độ $\langle Ox'y' \rangle$ là:

$$
\lambda _ { 1 } x ^ { \prime 2 } + \lambda _ { 2 } y ^ { \prime 2 } + 2 a _ { 1 } ^ { \prime } x ^ { \prime } + 2 a _ { 2 } ^ { \prime } y ^ { \prime } + a _ { 0 } = 0 .
$$

(Trường hợp $a_{12} = 0$ thì không cần bước này).

Đưa vào các hệ số $\lambda _ { 1 } , \lambda _ { 2 } , a _ { 1 } ^ { \prime } , a _ { 2 } ^ { \prime } , a _ { 0 }$ ta có các đường bậc 2 sau:

1) Nếu $\lambda _ { 1 } \lambda _ { 2 } \neq 0$, phương trình (6.69) viết được thành

$$
\lambda _ { 1 } \left( x ^ { \prime } + \frac { a _ { 1 } ^ { \prime } } { \lambda _ { 1 } } \right)^{2} + \lambda _ { 2 } \left( y ^ { \prime } + \frac { a _ { 2 } ^ { \prime } } { \lambda _ { 2 } } \right)^{2} + a _ { 0 } = 0 .
$$

Tiến hành hệ tọa độ $Ox'y'$ đến hệ tọa độ $\Omega XY$:

$$
X = x ^ { \prime } + \frac { a ^ { \prime } _ { 1 } } { \lambda _ { 1 } } , Y = y ^ { \prime } + \frac { a ^ { \prime } _ { 2 } } { \lambda _ { 2 } } ,
$$

$$
\lambda _ { 1 } X ^ { 2 } + \lambda _ { 2 } Y ^ { 2 } + a ^ { \prime } _ { 0 } = 0 .
$$

(6.70)

a) $a _ { 0 } ^ { \prime } \neq 0$, $\lambda _ { 1 } \lambda _ { 2 } > 0$, $\lambda _ { 1 } a _ { 0 } ^ { \prime } < 0 : ( 6 . 7 0 )$ là phương trình một elip;

b) $a _ { 0 } ^ { \prime } \neq 0$, $\lambda _ { 1 } \lambda _ { 2 } > 0$, $\lambda _ { 1 } a _ { 0 } ^ { \prime } > 0 : ( 6 . 7 0 )$ là phương trình một elip ảo;

c) $a _ { 0 } ^ { \prime } \neq 0$, $\lambda _ { 1 } \lambda _ { 2 } < 0 : ( 6 . 7 0 )$ là phương trình một hyperbol;

d) $a _ { 0 } ^ { \prime } = 0, \lambda _ { 1 } \lambda _ { 2 } < 0$: Phương trình (6.70) có dạng $\big | \lambda _ { 1 } \big | X ^ { 2 } - \big | \lambda _ { 2 } \big | Y ^ { 2 } = 0$ là phương trình cặp đường thẳng cắt nhau.

e) $a _ { 0 } ^ { \prime } = 0$, $\lambda _ { 1 } \lambda _ { 2 } > 0$: Phương trình (6.70) có dạng $\big | \lambda _ { 1 } \big | X ^ { 2 } + \big | \lambda _ { 2 } \big | Y ^ { 2 } = 0$ là phương trình một điểm.

2) Trường hợp trong hai giá trị $\lambda _ { 1 } , \lambda _ { 2 }$ bằng 0:

a) $\lambda _ { 1 } = 0$, $\lambda _ { 2 } \neq 0$, $\boldsymbol{a} _ { \mathrm{~1~} } ' \neq 0$: Phương trình (6.68) có thể viết lại:

$$
\lambda _ { 2 } \left( y' + \frac{a_2'}{\lambda _ { 2 }} \right)^2 + 2 a_1' (x' + a_0') = 0.
$$

Đặt $\boldsymbol{X} = x' + a_0'$, $Y = y' + \frac{a_2'}{\lambda _ { 2 }}$ ta có: $Y^2 = -2 \frac{a_1'}{\lambda _ { 2 }} X$

Vậy (6.71) là một parabol nhận trục $\Omega X$ làm trục đối xứng.

b) $\lambda _ { 2 } = 0$, $\lambda _ { 1 } \neq 0$, $\boldsymbol{a} _ { \mathrm{~2~} } ' \neq \boldsymbol{0}$: Đường cong (6.68) là một parabol nhận trục ΩY làm trục đối xứng.

c) $\lambda _ { 1 } = 0$, $\lambda _ { 2 } \neq 0$, $\boldsymbol{a} _ { \mathrm{~1~} } ' = 0$ hay $\lambda _ { 1 } \neq 0$, $\lambda _ { 2 } = 0$, $\boldsymbol{a} _ { \mathrm{~2~} } ' = \boldsymbol{0}$: Đường cong (6.68) là một điểm.

Ví dụ 6.25: Cho đường bậc hai có phương trình $(G): 5x^2 - 4xy + 8y^2 = 36$:

Xét dạng toàn phương: $Q(x, y) = 5x^2 - 4xy + 8y^2$.

Ma trận trong cơ sở chính tắc $A = \left[ \begin{array} { l l } { 5 } & { - 2 } \\ { - 2 } & { 8 } \end{array} \right]$ có giá trị riêng $\lambda _ { 1 } = 4 , \lambda _ { 2 } = 9$ . Chéo hóa tọa độ được:

$$
\left\{ \begin{array} { l } { x = \frac { 2 } { \sqrt { 5 } } X + \frac { 1 } { \sqrt { 5 } } Y } \\ { y = - \frac { 1 } { \sqrt { 5 } } X + \frac { 2 } { \sqrt { 5 } } Y } \end{array} \right. .
$$

Phương trình của $( G )$ trong hệ tọa độ $\hat{\mathbf{d}}\hat{\mathbf{o}}$ mới:

$$
4 X ^ { 2 } + 9 Y ^ { 2 } = 36 \Rightarrow \frac { X ^ { 2 } } { 9 } + \frac { Y ^ { 2 } } { 4 } = 1 .
$$

Vậy $( G )$ là một elip có bán kính trục lớn bằng 3 và bán kính trục nhỏ bằng 2.

# 6.6.2. Hệ tọa độ chuẩn trong không gian và các mặt bậc hai  
## 6.6.2.1. Tọa độ của một vector và tọa độ của một điểm trong không gian

Trong không gian ta xét ba trục vuông góc chung góc $O \colon x ^ { \prime } O x$, y'Oy, $z ^ { \prime } O z$ tạo thành một hệ trục gọi là hệ trục tọa độ vuông góc Descartes trong không gian, viết tắt Oxyz. Trên ba trục tọa độ này ta chọn các véc tơ đơn vị lần lượt là $\vec { i }$, $\overrightarrow { j }$, $\overrightarrow { k }$. Ta chỉ xét hệ trục Oxyz là hệ thuận, nghĩa là nếu dùng theo chiều véc tơ $\overrightarrow { k }$ ta sẽ thấy $\vec { i }$ quay sang $\overrightarrow { j }$ theo ngược chiều kim đồng hồ.

Với mỗi véc tơ $\overrightarrow { \nu }$ ta có thể viết

$$
\begin{array} { r } { \overrightarrow { \nu } = \nu _ { x } \overrightarrow { i } + \nu _ { y } \overrightarrow { j } + \nu _ { z } \overrightarrow { k } = \Big \langle \overrightarrow { \nu } , \overrightarrow { i } \Big \rangle \overrightarrow { i } + \Big \langle \overrightarrow { \nu } , \overrightarrow { j } \Big \rangle \overrightarrow { j } + \Big \langle \overrightarrow { \nu } , \overrightarrow { k } \Big \rangle \overrightarrow { k } \mathrm { ~ , ~ } } \end{array}
$$

trong đó $\nu _ { x } , \nu _ { y } , \nu _ { z }$ lần lượt là hình chiếu của $\vec { \nu }$ xuống các trục $O x , O y , O z$:

$( \nu _ { x } , \nu _ { y } , \nu _ { z } )$ được gọi là tọa độ của véc tơ $\overrightarrow { \nu }$, ký hiệu $\overrightarrow { \nu } = ( \nu _ { x } , \nu _ { y } , \nu _ { z } )$.

# 6.6.2.2. Một số mặt bậc 2 dạng chính tắc thường gặp trong không gian

a) Ellipsoid (Elipxoit) là mặt $(E)$ bậc 2 có phương trình dạng chính tắc:

$$
\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1.
$$

\*) Nếu 2 trong 3 số $a, b, c$ bằng nhau thì ta có mặt ellipsoid tròn xoay. Chẳng hạn nếu $a = b$ thì ta có mặt tròn xoay quanh trục $z'Oz$. Nếu $a = b = c = R$ thì ta có mặt cầu tâm $O$ bán kính $R$

\*) Góc $O$ là tâm đối xứng, các mặt phẳng tọa độ là mặt phẳng đối xứng;

\*) Giao tuyến với các mặt phẳng song song với các mặt phẳng tọa độ là các elip.

b) Hyperboloid mặt tăng (Hyperboloid) là mặt $(H_1)$ bậc 2 có phương trình dạng chính tắc:

$$
\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1.
$$

\*) Góc $O$ là tâm đối xứng;

\*) Các trục tọa độ là trục đối xứng;   
\*) Các mặt phẳng tọa độ là mặt phẳng đối xứng;   
\*) Giao của $(H_1)$ với mặt phẳng vuông góc với trục $z'Oz$ là mặt elip;   
\*) Giao của $(H_1)$ với mặt phẳng chéo trục $z'Oz$ là mặt hyperbol.

Tương tự có các Hyperboloid mặt tăng:

$$
{ \frac { x ^ { 2 } } { a ^ { 2 } } } - { \frac { y ^ { 2 } } { b ^ { 2 } } } + { \frac { z ^ { 2 } } { c ^ { 2 } } } = 1 , \ - { \frac { x ^ { 2 } } { a ^ { 2 } } } + { \frac { y ^ { 2 } } { b ^ { 2 } } } + { \frac { z ^ { 2 } } { c ^ { 2 } } } = 1 .
$$

c) Hyperboloid hai tảng là mặt $( H _ { 2 } )$ bậc 2 có phương trình dạng chính tắc:

$$
{ \frac { x ^ { 2 } } { a ^ { 2 } } } + { \frac { y ^ { 2 } } { b ^ { 2 } } } - { \frac { z ^ { 2 } } { c ^ { 2 } } } = - 1 .
$$

\*) Mặt phẳng vuông góc với trục $z ^ { \prime } O z$ có phương trình $z = h$ sao cho $\left| h \right| > c$ cắt $( H _ { 2 } )$ theo một elipps;

\*) Giao của $( H _ { 2 } )$ với mặt phẳng chĩa trục $z ^ { \prime } O z$ là mặt Hyperbol.

d) Paraboloid elliptic (Paraboloit éliptic) theo trục $O z$ là mặt $( P _ { 1 } )$ bậc 2 có phương trình dạng chính tắc:

$$
\frac { x ^ { 2 } } { a ^ { 2 } } + \frac { y ^ { 2 } } { b ^ { 2 } } = 2 z .
$$

\*) Giao tuyến của $( P _ { 1 } )$ với mặt phẳng vuông góc trục $z ^ { \prime } O z$ nằm phía trên mặt phẳng Oxy là mặt ellipse;

\*) Giao tuyến của $( P _ { 1 } )$ với mặt phẳng chĩa trục $z ^ { \prime } O z$ là Parabol.
