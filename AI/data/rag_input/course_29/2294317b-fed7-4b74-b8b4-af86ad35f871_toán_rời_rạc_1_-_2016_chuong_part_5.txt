# 3.4. Thuật toán quay lui (Back track)

Phương pháp sinh kế tiếp có thể giải quyết được các bài toán liệt kê khi ta nhận biết được cấu hình đầu tiên và cấu hình cuối cùng của bài toán. Tuy nhiên, không phải cấu hình sinh kế tiếp nào cũng dùng để sinh một cách đơn giản từ cấu hình hiện tại, ngay cả việc phát hiện cấu hình ban đầu cũng không phải dễ tìm vì nhiều khi chúng ta phải chứng minh sự tồn tại của cấu hình. Do đó, thuật toán sinh kế tiếp chỉ giải quyết được những bài toán liệt kê đơn giản. Đối với các bài toán phức tạp hơn, người ta thường dùng thuật toán quay lui (Back Track) sẽ được trình bày dưới đây.

Nội dung chính của thuật toán này là xây dựng dần các thành phần của cấu hình bằng cách thử tất cả các khả năng. Giả sử cần tìm một cấu hình của bài toán $\mathbf{x} = (\mathbf{x}_1, \mathbf{x}_2, \ldots, \mathbf{X}_n)$ mà $i-1$ thành phần $\mathbf{x}_1$, $\mathbf{X}_2$, $\mathbf{X}_{i-1}$ đã được xác định, bây giờ ta xác định thành phần thứ $i$ của cấu hình bằng cách duyệt tất cả các khả năng có thể và danh sách các khả năng từ 1 đến $n$. Với mỗi khả năng $j$, kiểm tra xem $j$ có hợp nhận được hay không. Khi đó có thể xảy ra hai trường hợp:

Nếu chấp nhận j thì xác định $\mathbf{X}_{\mathrm{i}}$ theo j, nếu i=n thì ta được một câu hình cần tìm, ngược lại xác định tiếp thành phần i.

Nếu thứ đã tất cả các khả năng n mà không có khả năng nào dùng chấp nhận thì quay lại bước trước đó để xác định lại $\mathbf{X}_{\mathrm{i-1}}$:

Điểm quan trọng nhất của thuật toán là phải ghi nhớ lại mỗi bước đã đi qua, nhưng khả năng nào đã dùng thử để tránh sự trùng lặp. Để nhớ lại những bước duyệt trước đó, chương trình cần được tổ chức theo cơ chế ngăn xếp (Last in first out). Vì vậy, thuật toán quay lui rất phù hợp với những phép gọi đệ qui. Ví dụ 4. Bài toán Xếp Hậu. Liệt kê tất cả các cách xếp n quân hậu trên bàn cờ n x n sao cho chúng không ăn được nhau.

Lời giải. Bàn cờ có n hàng được đánh số từ 1 đến n, n cột được đánh số từ 1 đến n; Bàn cờ có \(n^2\) đường chéo xuôi được đánh số từ 1 đến 2*n - 1, 2*n - 1 đường chéo ngược được đánh số từ 1 đến 2*n - 1. Ví dụ: với bàn cờ \(8 \times 8\), chúng ta có 8 hàng được đánh số từ 1 đến 8, 8 cột được đánh số từ 1 đến 8, 15 đường chéo xuôi, 15 đường chéo ngược được đánh số từ 1 đến 15.

Vì trên mỗi hàng chỉ xếp được đúng một quân hậu, nên ta chỉ cần quan tâm đến quân hậu được xếp ở cột nào. Từ đó dẫn đến việc xác định bộ thành phần ${ \bf X } _ { 1 }$, $\mathbf { X } _ { 2 }$, ..., $\mathbf { X } _ { n }.$, trong đó $\mathbf { x } _ { i } = \mathbf { j }$ được hiểu là quân hậu tại dòng $i$ xếp vào cột thứ $j$. Giá trị của $i$ được nhận từ 1 đến $n$; giá trị của $j$ cũng được nhận từ 1 đến $n$, nhưng thỏa mãn điều kiện $(i,j)$ chưa bị quân hậu khác chiếu đến theo cột, đường chéo xuôi, đường chéo ngược.

Việc kiểm soát theo hàng ngang là không cần thiết vì trên mỗi hàng chỉ xếp đúng một quân hậu. Việc kiểm soát theo cột được ghi nhận bằng biến logic chuaxetj với giá trị chuaxetj=True nếu cột j còn trống, chuaxetj=False nếu cột j không còn trống. Để ghi nhận đường chéo xuôi và đường chéo ngược có ích tại ô (i,j) hay không, sử dụng phương trình $\mathbf { i } + \mathbf { j } = $ const và $\mathbf { i } - \mathbf { j } = $ const, đường chéo nhất được ghi nhận bằng biến XUOIj, đường chéo thứ 2 được ghi nhận bằng biến NGUOCj với qui tắc nếu đường chéo nào còn trống thì giá trị true của nó là True ngược lại là False. Như vậy, cột j được chấp nhận khi cả 3 biến $\mathbf { X U O I } _ { \mathrm { i + j } }$, $\mathbf { N G U O C } _ { \mathrm { i - j } }$ đều có giá trị True. Các biến này phải được khởi đầu giá trị False, gán lại giá trị False khi xếp xong quân hậu thứ i và trả lại giá trị True khi đưa ra kết quả.

Dưới đây là chương trình bằng thuật toán quay lui.

```cpp
#include <iostream>
#include<stdlib.h>
#define MAX 100
#define TRUE 1
#define FALSE 0

int X[MAX], XUOI[MAX], NGUOC[MAX], chuaxet[MAX];
int n, dem = 0;

void Init(void) {
    cout << "Nhap n = ";
    cin >> n;
    for (int i = 1; i <= n; i++) chuaxet[i] = TRUE;
    for (int i = 1; i <= (2 * n - 1); i++) XUOI[i] = TRUE, NGUOC[i] = TRUE;
}

void Result(void) {
    cout << "Phương án " << dem + 1 << ": ";
    for (int i = 1; i <= n; i++) cout << X[i] << " ";
}

void Try(int i){
    for (int j = 1; j <= n; j++) {
        if (chuaxet[j] && XUOI[i - j + n] && NGUOC[i + j - 1]) {
            X[i] = j;
            chuaxet[j] = FALSE;
            XUOI[i - j + n] = FALSE;
            NGUOC[i + j - 1] = FALSE;
            if (i == n) Result();
            else Try(i + 1);
            chuaxet[j] = TRUE;
            XUOI[i - j + n] = TRUE;
            NGUOC[i + j - 1] = TRUE;
        }
    }
}

int main(){
    Init();
    Try(1);
    system("PAUSE");
    return 0;
}
```
