## 3.1.1. Định nghĩa.

Cho hàm hai biến số \( z = f(x, y) \) xác định trên cung \(\widetilde{AB}\).

\( + \) Phân hoạch \( P \) cung \(\widetilde{AB} \) bằng \( n \) điểm

$$
A = C_0, C_1, C_2, \ldots, C_n = B.
$$

Ký hiệu \( \Delta_i \) là độ dài các cung \(\widetilde{C_{i-1}C_i}\), \(\forall i = 1, 2, \ldots, n\). \( \Delta_P = \max\{\Delta_1, \Delta_2, \ldots, \Delta_n\} \)

\( + \) Chọn một điểm tùy ý \( M_i \in \widehat{C_{i-1}C_i} \)

Khi đó

$$
\sigma_P = \sum_{i=1}^n f(M_i)\Delta_i
$$

được gọi là tổng tích phân đường loại I của hàm \( f(x, y) \) trên cung \(\widetilde{AB}\). Nếu giới hạn

$$
I = \lim_{\Delta_P \to 0} \sigma_P
$$

tồn tại, không phụ thuộc vào phép phân hoạch \( P \) và chọn điểm \( M_i \), thì \( I \) được gọi là tích phân đường loại I của hàm \( f(x, y) \) trên cung \(\widetilde{AB}\) (hay ta còn nói \( f(x, y) \) khả tích trên cung \(\widetilde{AB} \) và được ký hiệu là \( \int_{AB} f(x, y)\, ds\). Người ta chứng minh được rằng nếu cung \(\widetilde{AB}\) trơn từng khúc (cung xác định hàm số khả vi liên tục từng khúc) và hàm \( f(x, y) \) liên tục trên \(\widetilde{AB} \), thì hàm số \( f(x, y) \) khả tích trên \(\widetilde{AB}\).

# 3.2. Tích phân đường loại 2.

3.2.1. Định nghĩa.

Cho hàm vector $\vec { F } = ( P , Q , R )$ xác định trên cung $\widetilde { A B }$. Người ta còn viết $F$ dưới dạng $\vec { F } = P \vec { i } + Q \vec { j } + R \vec { k }$ hay

$$
F ( x , y , z ) = P ( x , y , z ) \vec { i } + Q ( x , y , z ) \vec { j } + R ( x , y , z ) \vec { k } .
$$

Phép phân hoạch $(P)$ cung $\widetilde { A B }$ bới các điểm

$$
A _ { 0 } = A , A _ { 1 } , . . . , A _ { n } = B.
$$

Chọn $M _ { i } ( x _ { i } , y _ { i } , z _ { i } ) \in \widetilde { A _ { i - 1 } A _ { i } } \subset \widetilde { A B }$ với mọi $i = 1, 2, . . . , n$. Giả sử rằng $\overrightarrow { A _ { i - 1 } A _ { i } } = ( \Delta x _ { i } , \Delta y _ { i } , \Delta z _ { i })$. Khi đó,

$$
{ \cal I } _ { n } = \sum _ { i = 1 } ^ { n } \vec { F } ( M _ { i } ) \overrightarrow { A _ { i - 1 } A _ { i } }
$$

Đường gọi là tổng tích phân đường loại 2 của hàm véc tơ $\vec{F}$ trên cung $\widetilde{AB}$ xác định bởi phép phân hoạch $(P)$. Nếu khi $n \to \infty$ sao cho max $\Delta_{x_i} : i = 1, 2, ..., n \to 0$, max $\Delta_{y_i} : i = 1, 2, ..., n \to 0$, max $\Delta_{z_i} : i = 1, 2, ..., n \to 0$, tổng tích phân $I_n$ dẫn đến giới hạn xác định $I$, không phụ thuộc vào phép phân hoạch $(P)$ và phép chọn điểm $M_i$, thì $I$ được gọi là tích phân đường loại 2 của hàm véc tơ $\vec{F}$ trên cung $\widetilde{AB}$ và ký hiệu

$$
I = \underbrace{\int_{AB} P dx + Q dy + R dz}_{\text{đường từ A đến B}}.
$$

Theo cách viết truyền thống, người ta còn viết dưới dạng

$$
\int\limits_{\overline{AB}} P(x, y, z) dx + Q(x, y, z) dy + R(x, y, z) dz.
$$

Trong trường hợp đặc biệt khi cung $\widetilde{AB}$ là đường cong khép kín, tích phân đường loại 2 trên cung $\widetilde{AB}$ được viết

$$
\oint P(x, y, z) dx + Q(x, y, z) dy + R(x, y, z) dz.
$$

3.2.2. Nhận xét.

Khi cung $\widetilde{AB}$ trong mặt phẳng tọa độ $(Oxy)$, hàm véc tơ $\vec{F} = (P, Q)$, tích phân đường loại 2 của hàm $\vec{F}$ trên cung $\widetilde{AB}$ được ký hiệu bởi

$$
\int_{\overline{AB}} P(x, y) dx + Q(x, y) dy.
$$

Đặc biệt khi cung $\widetilde{AB}$ là một đoạn $[a, b]$ nào đó trên $\mathbb{R}$, hàm $f : [a, b] \to \mathbb{R}$, tích phân đường loại 2 của hàm $f$ trên $\widetilde{AB}$ trở thành tích phân xác định.

3.2.3. Tích chất cơ học của tích phân đường loại 2.

Để tính công sinh ra trong một điểm $M$ chuyển động độc lập theo cung $\widetilde{AB}$ từ điểm $A$ đến điểm $B$ dưới tác dụng của một lực $\vec{F} = \vec{F}(M)$, ta thực hiện phép phân hoạch $(P)$ như trong định nghĩa trên. Phép chia cung $\widetilde{AB}$ nhỏ nhất đến mức ta có thể coi cung $\widetilde{A_{i-1} A_i}$ như đoạn thẳng, lực tác dụng lên chất điểm trên cung $\widetilde{A_{i-1} A_i}$ không đổi và bằng $\vec{F}(M_i)$. Khi đó, công sinh ra trên cung $\widetilde{A_{i-1} A_i}$ xấp xỉ với tích vô hướng $\begin{array}{r}\vec{F}(M_i)\overrightarrow{A_{i-1} A_i}\end{array}$. Vậy $I_n$ xác định bởi định nghĩa trên xấp xỉ với công sinh ra trên cung $\widetilde{AB}$. Do đó, giá trị của tích phân đường loại 2 $\operatorname*{lim}_{n \to \infty} I_n$ chính là công san sinh khi chất điểm $M$ chuyển động độc lập theo quy đạo $\widetilde{AB}$ từ điểm $A$ đến điểm $B$:

3.2.4. Cách tính tích phân đường loại 2.

$$

$$

$$

$$

trong đó $\Delta _ { t _ { i } } = t _ { i } - t _ { i - 1 }$. Khi đó, điểm $M _ { i } \big( x ( \tau _ { i } ) , y ( \tau _ { i } ) , z ( \tau _ { i } ) \big) \in \widetilde { A }_{i-1} \overline{A}_{i}$ và

$$

$$

Vé phải là tổng tích phân của hàm số

$$
P \big ( x ( t ) , y ( t ) , z ( t ) \big ) x ^ { \prime } ( t ) + Q \big ( x ( t ) , y ( t ) , z ( t ) \big ) y ^ { \prime } ( t ) + R \big ( x ( t ) , y ( t ) , z ( t ) \big ) z ^ { \prime } ( t )
$$

trên đoạn $[ a, b ]$. Đặt $\Delta _ { P } = \operatorname*{max} \{ \Delta _ { t _ { i } } : i = 1, 2, . . . , n \}$. Khi $\Delta _ { t _ { i } } \to 0$, ta có

$$

3.5.1. Công thức Stokes

Cho $S$ là một mặt định hướng trơn, biên $\partial S$ là một đường cong khép kín, các hàm số $P , Q , R$ và các đạo hàm của chúng liên tục trên $S$. Khi đó

trong đó đường lấy tích phân theo chiều dương (là chiều đi mà ta nhìn thấy mặt $S$ bên trái). Chứng minh.

$$

# 4.1. Khái niệm chung về phương trình vi phân

Có rất nhiều mô hình toán học liên quan đến việc nghiên cứu và giải các phương trình vi phân, ta nhắc lại một số mô hình bài toán quen thuộc thường gặp trong chương trình phổ thông liên quan đến phương trình vi phân.

# 4.1.1. Các bài toán

Bài toán 1. Một vật có khối lượng $m$ được đặt lên một lò xo đàn hồi với hệ số $k > 0$. Hãy xác định quy luật dao động của vật?

Giải. Chọn trục Oy thẳng đứng hướng từ trên xuống, gốc $O$ đặt tại trong tâm vật ở vị trí cân bằng. Từ đó ta dễ dàng đưa ra phương trình chuyển động của vật theo định luật Newton:

$$
m \frac{d^2 y}{dt^2} = -k y - \lambda \frac{dy}{dt}.
$$

Đặt $\textstyle a = \frac{k}{m}$ và $\textstyle b = \frac{\lambda}{m}$ thì ta có phương trình chuyển động của lò xo có dạng thu gọn:

$$
y'' + a y' + b y = 0.
$$

Đây là phương trình vi phân bậc 2 tuyến tính.

Bài toán 2. Một thanh kim loại được nung nóng đến $120^{\circ} C$ được đặt trong môi trường luôn có nhiệt độ không đổi $25^{\circ} C$. Tìm quy luật thay đổi nhiệt độ của thanh kim loại.

Giải. Gọi $y(x)$ là nhiệt độ của thanh kim loại tại thời điểm $x$. Theo định luật Newton về sự giảm nhiệt của vật thì tốc độ giảm nhiệt tỷ lệ với nhiệt độ của vật và nhiệt độ $y(x) - 25$ của môi trường tại thời điểm đó. Do vậy, ta có

$$
\frac{dy}{dt} = -k \big( y(t) - 25 \big), \ k > 0,
$$

là phương trình vi phân cấp 1.

4.1.2. Định nghĩa

Phương trình vi phân là phương trình quan hệ giữa biến độc lập $x$, hàm số cần tìm $y$ và các đạo hàm $y', y'', ..., y^{(n)}$ của nó. Hay phương trình có dạng như sau:

$$
F(x, y, y', y'', ..., y^{(n)}) = 0
$$

hoặc

$$
y^{(n)} = f(x, y, y', y'', ..., y^{(n-1)}).
$$

Cấp cao nhất $n$ của đạo hàm của hàm số $y$ được gọi là cấp của phương trình vi phân. Ví dụ như, phương trình vi phân (4.2) là phương trình vi phân cấp 1 và (4.1) là phương trình vi phân cấp 2. Nghiệm của phương trình vi phân (4.3) là tất cả các hàm số $y = \varphi(x)$ thỏa mãn phương trình.

4.2. Phương trình vi phân cấp một

## 4.2.1. Định nghĩa và sự tồn tại nghiệm

Phương trình vi phân cấp một là phương trình vi phân có dạng

$$
F(x, y, y') = 0.
$$

Phương trình (4.4) được gọi là giải được đối với $y'$, nếu nó có thể viết được dưới dạng:

$$
y' = f(x, y).
$$

Bài toán Cauchy: Tìm hàm số $y = y(x)$ là nghiệm của phương trình (4.4) hoặc (4.5) và điều kiện ban đầu $y(x_0) = y_0$：

Ví dụ 4.1. Giải bài toán Cauchy

$$
y' = 3x^2, \quad y(0) = 1.
$$

Giải: Dễ thấy $y = x^3 + C$ là nghiệm của phương trình. Với $x = 0$, $y = 1$, ta có $C = 1$. Vậy nghiệm của bài toán là $y = x^3 + 1$：

Hàm số $y = \varphi(x, C)$, với $C$ là một hằng số tùy ý, được gọi là nghiệm tổng quát của phương trình vi phân cấp một trên miền $D \subseteq \mathbb{R}^2$, nếu $y = \varphi(x, C)$ thỏa mãn phương trình (4.4) với mọi hằng số $C$ và tồn tại duy nhất hằng số $C_0$ sao cho $y = \varphi(x, C_0)$ là nghiệm của bài toán Cauchy. Nếu không tìm được nghiệm tổng quát mà tìm được nghiệm dưới dạng một hệ thức dạng ẩn $\phi(x, y, C) = 0$, thì hệ thức này được gọi là tích phân tổng quát của

phương trình vi phân cấp 1. Chú ý rằng, không phải bất kỳ nghiệm nào của phương trình vi phân cũng nhận được từ nghiệm tổng quát bằng cách cho hằng số $C$ các giá trị cụ thể $\tilde { \mathrm { e } }$. Nghiệm không thay đổi $\ddot { \mathrm { ~ e ~ } }$ nhận được từ nghiệm tổng quát dù $C$ lấy bất kỳ giá trị nào gọi là nghiệm kỳ dị (ta không nghiên cứu sau về nghiệm này).

Định lý 4.2. Nếu hàm $f ( x , y )$ liên tục trong miền $D \subseteq \mathcal { R } ^ { n }$ chứa $( x _ { 0 } , y _ { 0 } )$, thì bài toán Cauchy (4.5) và điều kiện ban đầu $y ( x _ { 0 } ) = y _ { 0 }$ có nghiệm $y = y ( x )$ xác định trong lân cận của điểm $x _ { 0 }$. Hơn nữa, nếu $\textstyle { \frac { \partial f } { \partial y } }$ cũng liên tục trên $D$ thì $y = y ( x )$ là nghiệm duy nhất.

Hiện tại, không có một phương pháp tổng quát nào để giải phương trình vi phân cấp 1. Dưới đây, ta xét một số phương trình vi phân cấp 1 thông dụng được giải bằng phương pháp tích phân.

4.2.2.Phương trình tách biệt Phương trình tách biệt là một phương trình vi phân cấp 1 có dạng

$$
f ( x ) d x + g ( y ) d y = 0 .
$$

Phương pháp giải: Lấy tích phân hai vế, ta có

$$
\int f ( x ) d x + \int g ( y ) d y = C .
$$

Nếu có $F ^ { \prime } ( x ) = f ( x )$ và $G ^ { \prime } ( y ) = g ( y)$, thì ta có tích phân tổng quát có dạng

$$
F ( x ) + G ( y ) = C .
$$

Ví dụ 4.3. Giải phương trình vi phân

$$
\frac{x \, dx}{1 + x^2} + \frac{y \, dy}{1 + y^2} = 0.
$$

Giải: Lấy tích phân hai vế, ta có

$$
\int \frac{x \, dx}{1 + x^2} + \int \frac{y \, dy}{1 + y^2} = 0.
$$

Khi đó,

$$
\frac{1}{2} \ln (1 + x^2) + \frac{1}{2} \ln (1 + y^2) = C_0,
$$

$$
(1 + x^2)(1 + y^2) = e^{2C_0} = C > 0.
$$

Vậy phương trình có nghiệm dạng tích phân tổng quát

$$
(1 + x^2)(1 + y^2) = C > 0.
$$

Chú ý 4.4. Nếu phương trình tách biến có dạng

$$
f_1(x) g_1(y) \, dx + f_2(x) g_2(y) \, dy = 0,
$$

thì ta có thể đưa về phương trình tách biến. Đúng vậy, nếu $f_2(x) g_1(y) \neq 0$, bằng cách chia hai vế cho $f_2(x) g_1(y)$, ta nhận được

$$
\frac{f_1(x)}{f_2(x)} \, dx + \frac{g_1(y)}{g_2(y)} \, dy = 0,
$$

đó là phương trình tách biến. Ta xét các nghiệm kỳ dị trong các trường hợp $f_2(x) g_1(y) = 0$:

Ví dụ 4.5. Giải phương trình vi phân cấp một

$$
y' = xy(y + 2).
$$

Giải: Phương trình đã cho được viết dưới dạng:

$$
dy = xy(y + 2) \, dx.
$$

-Nếu $y(y + 2) \neq 0$, phương trình có dạng tách biến

$$
\frac{dy}{y(y + 2)} - x \, dx = 0.
$$

Lấy tích phân hai vế, ta có

$$
\int { \frac { d y } { y ( y + 2 ) } } - \int x d x = 0.
$$

Đề dạng nhận được

$$
\ln \left| { \frac { y } { y + 2 } } \right| - x ^ { 2 } = \ln | C | , C \neq 0.
$$

$$
\frac { y } { y + 2 } = C e ^ { x ^ { 2 } } , C \neq 0
$$

là tích phân tổng quát của phương trình đã cho.

-Nếu $y ( y + 2 ) = 0$ , thì $y = 0$ và $y = - 2$ cũng là nghiệm của phương trình đã cho.

Ví dụ 4.6. Giải phương trình $( 1 + x ) y d x + ( 1 - y ) x d y = 0.$

Giải: Nếu $x \neq 0 , \ y \neq 0$, phương trình trở thành:

$$
( \frac { 1 } { x } + 1 ) d x = ( 1 - \frac { 1 } { y } ) d y.
$$

Lấy tích phân hai vế, ta được

$$
\ln | x | + x = y - \ln | y | + C,
$$

$$
\ln | x y | + x - y = C.
$$

Với $x = 0 , \ y = 0$ cũng thỏa mãn phương trình, chúng biểu diễn hai đường tích phân kỳ dị.

Chú ý 4.7. Phương trình dạng

$$
y ^ { \prime } = f ( a x + b y + c )
$$

có thể đưa về được dạng tách biến. Điều này hiển nhiên với $b = 0$. Bằng cách sử dụng chú ý 4.5 trong trường hợp $a = 0$. Nếu $a b \neq 0$, thì đặt $z = a x + b y + c$. Khi đó, $z ^ { \prime } = a + b y ^ { \prime }$ và phương trình có dạng tách biến với biến $z$

$$
z ^ { \prime } = b f ( z ) + a.
$$

Phương trình được giải bằng cách sử dụng chú ý 4.5.

Ví dụ 4.8. Giải phương trình

Giải:

# 4.2.3 Phương trình tuyến tính

Phương trình tuyến tính cấp 1 là phương trình vi phân có dạng:
$$
y' + f(x)y = g(x),
$$
trong đó $f(x), g(x)$ là các hàm liên tục. Phương trình tuyến tính cấp 1 (4.6) được gọi là thuận nhất nếu $g(x) = 0$, là không thuận nhất nếu $g(x) \neq 0$. Để giải phương trình (4.6), trước hết ta giải phương trình thuận nhất tương ứng
$$
y' + p(x)y = 0.
$$

Nếu $y \neq 0$ phương trình trở thành
$$
\frac{dy}{y} = -f(x)dx,
$$
đây là phương trình tách biến có nghiệm:

$$
\ln | y | = - \int f (x) dx + \ln | C | ,
$$

với $C \neq 0$ là hằng số tùy ý. Do đó

$$
y = C e ^ { - \int f ( x ) d x }
$$

đây là nghiệm tổng quát của phương trình (4.7). Chú ý $y = 0$ cũng là một nghiệm của (4.7) và là một nghiệm riêng ứng với $\scriptstyle C = 0$

Để tìm nghiệm tổng quát của phương trình (4.6), ta coi $C$ là hàm số đối với biến $x$, ta cần tìm $C(x)$ để (4.8) thỏa mãn (4.6). Lấy đạo hàm hai vế của (4.8) rồi thay vào (4.6) ta được:

$$
\begin{array} { c } { e ^ { - \int f ( x ) d x } C ^ { \prime } ( x ) - C ( x ) f ( x ) e ^ { - \int f ( x ) d x } + f ( x ) C ( x ) e ^ { - \int f ( x ) d x } = g ( x ), } \\ { \frac { d C ( x ) } { d x } = g ( x ) e ^ { \int f ( x ) d x }. } \end{array}
$$

$$
C ( x ) = \int g ( x ) e ^ { \int f ( x ) d x } dx + K ,
$$

trong đó $K$ là hằng số tùy ý. Khi đó

$$
y = K e ^ { - \int f ( x ) d x } + e ^ { - \int f ( x ) d x } \int g ( x ) e ^ { \int f ( x ) d x } dx ,
$$

là nghiệm tổng quát của phương trình (4.6). Phương pháp giải như trên gọi là phương pháp biến thiên hằng số $C$.

Ví dụ 4.9. Giải phương trình

$$
( x ^ { 2 } + 1 ) y ^ { \prime } + x y = 1 ,
$$

thỏa mãn điều kiện $y | _ { x = 0 } = 2$

Giải: Phương trình thuận nhất tương ứng:

$$
( x ^ { 2 } + 1 ) y ^ { \prime } + x y = 0 \quad hay \quad \frac { d y } { y } = - \frac { x } { x ^ { 2 } + 1 }.
$$

Lấy tích phân hai vế, ta được

$$
y = \frac{C}{\sqrt{x^2 + 2}}.
$$

Đây là nghiệm tổng quát của phương trình thuận nhât. Ta xem $C$ là hàm số của $x$, thay vào phương trình không thuận nhât, ta có

$$
C' = \frac{1}{\sqrt{x^2 + 1}} \text{ nên } C = \ln(x + \sqrt{x^2 + 1}) + K.
$$

Vậy nghiệm tổng quát của phương trình không thuận nhât là:

$$
y = \frac{\ln(x + \sqrt{x^2 + 1}) + K}{\sqrt{x^2 + 1}}.
$$

Thay $x = 0, y = 2$ vào nghiệm tổng quát, ta nhận được $K = 2$ và do đó

$$
y = \frac{\ln(x + \sqrt{x^2 + 1}) + 2}{\sqrt{x^2 + 1}}.
$$

4.2.4 Phương trình Bernoulli

Phương trình vi phân có dạng

trong đó $f(x), g(x)$ là các hàm số liên tục, $\alpha$ là một số thực khác 0 và 1, được gọi là phương trình Bernoulli. Với $\alpha = 0$ hoặc $\alpha = 1$, thì phương trình (4.10) trở thành phương trình tuyến tính. Nếu $y^\alpha \neq 0$, chia hai vế của (4.10) cho $y^\alpha$, ta được

y' y^{-\alpha} + f(x) y^{1 - \alpha} = g(x).
$$

Đặt $z = y^{1 - \alpha}$, phương trình (4.10) trở thành

$$
z' + (1 - \alpha) f(x) z = (1 - \alpha) g(x).

Đây là phương trình tuyến tính cấp một đối với ẩn $z$

Ví dụ 4.10. Giải phương trình

$$
y' + \frac{2}{x} y = 3 x^2 y^\frac{4}{3}.
$$

Giải: Đây là phương trình Bernoulli với $\textstyle \alpha = \frac{4}{3}$. Nếu $y \neq 0$, chia hai vế của phương trình cho $y^{\frac{4}{3}}$, ta có

$$
y^{\frac{4}{3}} y' + \frac{2}{x} y^{1 - \frac{4}{3}} = 3 x^2.
$$

Đặt $z = y^{-\frac{1}{3}}$. Khi đó, $z' = -\frac{1}{3} y^{-\frac{4}{3}} y'$ và phương trình có dạng

$$
z' - \frac{2}{3x} z = - x^2.
$$

Đây là phương trình tuyến tính bậc 1 đối với biến $z$. Giải phương trình này, ta nhận được nghiệm tổng quát

$$
z = \left( -\frac{3}{7} x^{\frac{7}{3}} + C \right) x^{\frac{2}{3}}.
$$

Vậy phương trình đã cho có tích phân tổng quát là

$$
y^{-\frac{1}{3}} = \left( -\frac{3}{7} x^{\frac{7}{3}} + C \right) x^{\frac{2}{3}}.
$$

Ngoài ra, $y = 0$ cũng là nghiệm của phương trình đã cho.

Chú ý 4.11: Một số phương trình vi phân, khi coi $y$ là hàm của biến số $x$, nhận được phương trình không thuộc dạng xét. Do đó, ta có thể coi $x$ là hàm của biến số $y$ để nhận được phương trình quen thuộc.

Ví dụ 4.12: Giải phương trình

$$
(x^2 y^3 + xy) dy - dx = 0.
$$

Giải: Coi $x$ là một hàm số theo biến $y$, phương trình có dạng

$$
x' - y x = y^3 x^2,
$$

là một dạng của phương trình Bernoulli $\mathrm{d}o1$ với $x$, ở đây $\alpha = 2$. Khi đó, với $x \neq 0$, chia hai vế cho $x^2$, ta nhận được

$$
x^{-2} x' - y x^{-1} = y^3.
$$

Đặt $z = x^{-1}$, suy ra $z' = -x^{-2} x'$. Khi đó, phương trình có dạng

$$
z' + y z = -y^3,
$$

là phương trình tuyến tính cấp 1. Dùng công thức nghiệm tổng quát, ta có

$$
z = \left( -y^2 e^{\frac{y^2}{2}} + 2 e^{\frac{y^2}{2}} + C \right).
$$

Do đó, tích phân tổng quát của phương trình ban đầu là

$$
\frac{1}{x} = -y^2 + 2 + C e^{-\frac{y^2}{2}}.
$$

Hơn nữa, $x = 0$ cũng là nghiệm của phương trình đã cho.

# 4.2.5 Phương trình vi phân toàn phần

Phương trình vi phân toàn phần là một phương trình vi phân cấp 1 có dạng

$$
F(x, y) dx + G(x, y) dy = 0,
$$

trong đó $F(x, y)$, $G(x, y)$ và các đạo hàm riêng cấp một của chúng liên tục trong một miền đơn liên $D$ thỏa mãn điều kiện

$$
\frac{\partial F(x, y)}{\partial y} = \frac{\partial G(x, y)}{\partial x}.
$$

Nếu $D = \mathcal{R}^2$, theo định lý bổn mệnh đề tương đương, tồn tại một hàm $u(x, y)$ sao cho $du(x, y) = F(x, y)dx + G(x, y)dy$ và phương trình trên có dạng $du(x, y) = 0$. Khi đó, hàm số $u(x, y)$ được xác định bằng công thức

hoặc

$$
\begin{array}{l}
\displaystyle u(x, y) = \int_{x_0}^x F(x, y_0)dx + \int_{y_0}^y G(x, y)dy + K, \\
\displaystyle u(x, y) = \int_{y_0}^y F(x_0, y)dy + \int_{x_0}^x G(x, y)dx + K.
\end{array}
$$

Ví dụ 4.13. Giải phương trình:

$$
\begin{array}{c}
i) (3x^2 + 4y^3)dx + (12y^2x + 5y)dy = 0, \\
ii) (2xy^2 - 3y^3)dx + (7 - 3xy^2)dy = 0.
\end{array}
$$

Giải:

i) Ta thấy $\frac{\partial F}{\partial y} = 12y^2 = \frac{\partial G}{\partial x}$, nên đây là phương trình vi phân toàn phần. Nên hàm số $u(x,y) = \int_{x_0}^x (3x^2 + 4y^3)dx + \int_{y_0}^y (12y^2x + 5y)dy = x^3|_{x_0}^x + 4y^3x|_{x_0}^x + 4y^3x|_{y_0}^y + \frac{5}{2}y^2|_{y_0}^y = C$.

Chọn $x_0 = 0, y_0 = 0$, ta có tích phân tổng quát dạng

$$
x ^ { 3 } + 4 y ^ { 3 } x + 4 y ^ { 4 } + \frac { 5 } { 2 } y ^ { 2 } = C.
$$

ii) Với $y \neq 0$, chia hai vế cho $y^2$, ta được phương trình vi phân toàn phần

$$
( 2 x - 3 y ) d x + ( \frac { 7 } { y ^ { 2 } } - 3 x ) d y = 0.
$$

Vậy nghiệm tổng quát của phương trình là

$$
x ^ { 2 } - \frac { 7 } { y } - 3 x y = C.
$$

Ngoài ra, $y = 0$ cũng là nghiệm của phương trình.

Chú ý 4.14. Khi điều kiện (4.12) không thỏa mãn thì phương trình (4.11) không phải  
phương trình vi phân toàn phần. Nhưng ta có thể tìm một hàm $u(x, y)$ sao cho phương trình   
$$
u(x, y) F(x, y) dx + u(x, y) G(x, y) dy = 0 
$$
là phương trình vi phân toàn phần, hàm $u(x, y)$ gọi  
là thừa số tích phân.

Ví dụ 4.15. Giải phương trình vi phân

$$
( x ^ { 2 } - \sin ^ { 2 } y ) d x + x \sin 2 y d y = 0.
$$

Giải: Đặt $F = x^2 - \sin^2 y$ và $G = x \sin 2y$, ta có

$$
\frac{\partial F}{\partial y} = -2 \sin y \cos y, \quad \frac{\partial G}{\partial x} = \sin 2y.
$$

Như vậy, $\frac{\partial F}{\partial y} \neq \frac{\partial G}{\partial x}$ . Tìm thừa số tích phân $u(x, y)$ sao cho

$$
\frac{\partial (uF)}{\partial y} = \frac{\partial (uG)}{\partial x}, \quad \forall (x, y) \in \mathbb{R}^2.
$$

Khi đó, ta có

$$
u = e ^ { - \int { \frac { 2 } { x } } d x } = e ^ { - 2 \ln x } = { \frac { 1 } { x ^ { 2 } } }.
$$

Phương trình vi phân có dạng

$$
\left( 1 - { \frac { \sin ^ { 2 } y } { x ^ { 2 } } } \right) d x + { \frac { \sin 2 y } { x } } d y = 0,
$$

là một phương trình vi phân toàn phần. Giải phương trình này, ta có tích phân tổng quát

$$
x + { \frac { \sin ^ { 2 } y } { x } } = C.
$$

4.3.Phương trình vi phân cấp hai

4.3.1. Định nghĩa và sự tồn tại nghiệm

Phương trình vi phân cấp hai là phương trình có dạng

$$
F ( x , y , y ^ { \prime } , y ^ { \prime \prime } ) = 0,
$$

trong đó $F$ là hàm số xác định trên một miền $U$ trong $\mathcal{R}^4$. Phương trình (4.13) được gọi là giải độc đối với đạo hàm $y ^ { \prime \prime }$, nếu nó có thể viết dưới dạng

$$
y ^ { \prime \prime } = f ( x , y , y ^ { \prime } ).
$$

Bài toán Cauchy là bài toán tìm nghiệm của phương trình (4.14) thỏa mãn các điều kiện ban đầu:

$$
y ( x _ { 0 } ) = y _ { 0 }, y ^ { \prime } ( x _ { 0 } ) = y _ { 0 } ^ { \prime }.
$$

Hàm số $y = \varphi(x, C_1, C_2)$, trong đó $C_1, C_2$ là các hằng số tùy ý, được gọi là nghiệm tổng quát của phương trình (4.13) trong miền $D \subseteq \mathcal{R}^3$, nếu nó là nghiệm của phương trình với mọi $C_1, C_2$ và với mọi điểm $(x_0, y_0, y'_0) \in D$, tồn tại duy nhất cặp số $(C_1^0, C_2^0)$ sao cho $y = \varphi(x, C_1^0, C_2^0)$ là nghiệm của bài toán Cauchy. Hệ thức $\Phi(x, y, C_1, C_2) = 0$ xác định nghiệm tổng quát của phương trình cặp hai dưới dạng hàm ẩn theo $y$ được gọi là tích phân tổng quát của phương trình đó.

Sau đây ta cũng đưa ra điều kiện để phương trình (4.14) tồn tại nghiệm và có duy nhất nghiệm.

Định lý 4.16. Cho phương trình (4.14). Nếu $f(x, y, y')$, $\frac{\partial f}{\partial y}(x, y, y')$ và $\frac{\partial f}{\partial y'}(x, y, y')$ liên tục trong một miền $D$ nào đó trong $\mathcal{R}^3$ và $(x_0, y_0, y'_0)$ là một điểm thuộc $D$, thì trong một lân cận nào đó của điểm ${\boldsymbol{x}} = {\boldsymbol{x}}_0$, tồn tại duy nhất một nghiệm $y = y(x)$ của phương trình (4.14) thỏa mãn các điều kiện

$$
\begin{array} { r } { y | _ { x = x _ { 0 } } = y _ { 0 } , y ^ { \prime } | _ { x = x _ { 0 } } = y _ { 0 } ^ { \prime } . } \end{array}
$$

Định lý này ta sẽ không chứng minh mà thừa nhận nó. Sau đây, ta sẽ trình bày một số phương pháp giải phương trình vi phân cấp hai.

Ngoài ra, $y = 0$ là nghiệm của phương trình ban đầu, nhưng nó không thỏa mãn các điều kiện ban đầu.

4.3.3. Phương trình vi phân tuyến tính cấp 2

Phương trình vi phân tuyến tính cấp $\mathcal{Z}$ là một phương trình vi phân có dạng

$$
y'' + p(x) y' + q(x) y = f(x),
$$

trong đó các hàm số $p(x), q(x)$ và $f(x)$ liên tục trên khoảng $(a, b)$. Nếu $f(x) \neq 0$ với mọi $x \in (a, b)$, thì (4.15) được gọi là phương trình vi phân tuyến tính cấp 2 không thuận nhất. Nếu $f(x) = 0$ với mọi $x \in (a, b)$, thì (4.15) có dạng

$$
y^{\prime \prime} + p(x) y^{\prime} + q(x) y = 0,
$$

và được gọi là phương trình vi phân tuyến tính cấp 2 thuận nhất.

4.3.3.1. Cấu trúc nghiệm

Định lý 4.20. Nếu $y_{1} = y_{1}(x)$ và $y_{2} = y_{2}(x)$ là hai nghiệm của phương trình thuận nhất (4.16), thì $\bar{y} = C_{1} y_{1} + C_{2} y_{2}$ với $C_{1}, C_{2}$ là các hằng số tùy ý, cũng là nghiệm của phương trình thuận nhất (4.16).

Chứng minh: Ta chỉ cần thay $\bar{y} = C_{1} y_{1}(x) + C_{2} y_{2}(x)$ vào phương trình (4.11) và dựa vào $y_{1}(x), y_{2}(x)$ là nghiệm của phương trình này, ta có điều phải chứng minh.

Định nghĩa 4.21. Các hàm số $\hat{y}_{1} = y_{1}(x), y_{2} = y_{2}(x)$ được gọi là độc lập tuyến tính trên khoảng $(a, b)$, nếu tỉ lệ $\frac{y_{1}}{y_{2}} \neq C$, trong đó $C$ là hằng số trên khoảng $(a, b)$. Trong trường hợp trái lại, hai hàm số này được gọi là phụ thuộc tuyến tính.

Việc xét một hệ hàm phụ thuộc tuyến tính hay độc lập tuyến tính nhiều khi gặp khó khăn, trong trường hợp các hàm đã cho khả vi một số lần cần thiết, việc nghiên cứu đó có thể đơn giản hơn nhờ định thức Wronski dưới đây.

Định nghĩa 4.22. Giả sử các hàm số $y_{1}(x)$, $y_{2}(x)$ khả vi trên khoảng $(a, b)$. Khi đó định thức

$$
\begin{array} { r l }
W ( y _ { 1 } ( x ) , ~ y _ { 2 } ( x ) ) = W ( x )
& = \left| 
\begin{matrix}
y _ { 1 } ( x ) & y _ { 2 } ( x ) \\
y _ { 1 } ^ { \prime } ( x ) & y _ { 2 } ^ { \prime } ( x )
\end{matrix} 
\right|
\end{array}
$$

được gọi là định nghĩa Vronski của các hàm $y_1(x), y_2(x)$ trên $(a, b)$.

Định lý 4.23. Nếu hai hàm số $y _ { 1 } ( x ) , \ y _ { 2 } ( x )$ phụ thuộc tuyến tính trên $( a , b )$ thì $W ( y _ { 1 } , y _ { 2 } ) = 0$ trên đoạn đó.

Chứng minh: Thay $y _ { 2 } ( x ) = k y _ { 1 } ( x )$ vào định nghĩa Vronski ta có điều phải chứng minh.

Định lý 4.24. Các nghiệm $y _ { 1 } , y _ { 2 }$ của phương trình vi phân tuyến tính cấp 2 thuận nhất (4.16) là độc lập tuyến tính trên đoạn $( a , b )$ khi và chỉ khi định thức Vronski $W ( y _ { 1 } , y _ { 2 } ) \neq 0$ tại mọi điểm trên khoảng đó.

Chứng minh: Nếu $W ( y _ { 1 } , y _ { 2 } ) \neq 0$ trên $( a , b )$, thì theo định lý 4.23, các hàm số $y _ { 1 } , y _ { 2 }$ là độc lập tuyến tính trên đoạn $( a , b )$. Ngược lại, cho các nghiệm $y _ { 1 } , y _ { 2 }$ của phương trình vi phân tuyến tính cấp 2 thuận nhất (4.16) là độc lập tuyến tính trên đoạn $( a , b )$. Bằng phản chứng, giả sử rằng tồn tại $x _ { 0 } \in ( a , b )$ sao cho $W ( y _ { 1 } ( x _ { 0 } ) , y _ { 2 } ( x _ { 0 } ) ) = 0$. Khi đó, ta có hệ phương trình

$$
\left\{ \begin{array} { l l } { \alpha _ { 1 } y _ { 1 } ( x ) + \alpha _ { 2 } y _ { 2 } ( x ) = 0 , } \\ { \alpha _ { 1 } y _ { 1 } ^ { \prime } ( x ) + \alpha _ { 2 } y _ { 2 } ^ { \prime } ( x ) = 0 , } \end{array} \right.
$$

có nghiệm không tầm thường $(\alpha_1, \alpha_2) \neq (0, 0)$. Theo định lý 4.20, $y = \alpha _ { 1 } y _ { 1 } ( x ) + \alpha _ { 2 } y _ { 2 } ( x )$ cũng là nghiệm của phương trình thuần nhất (4.16). Hơn nữa, theo điều kiện ban đầu (4) thì nghiệm đó thỏa mãn $y(x_0) = 0$, $y'(x_0) = 0$.

Theo tính duy nhất nghiệm của bài toán Cauchy, thì $y = 0$ là nghiệm trên $(a, b)$. Như vậy, $y = \alpha _ { 1 } y _ { 1 } ( x ) + \alpha _ { 2 } y _ { 2 } ( x ) = 0$ trên $( a , b )$, hay $y_1$ và $y_2$ phụ thuộc tuyến tính trên $(a, b)$. Điều này trái với giả thiết. Định lý được chứng minh.

Định lý sau đây chỉ ra rằng nếu có hai nghiệm riêng độc lập tuyến tính của phương trình (4.16) thì ta đưa ra được nghiệm tổng quát của phương trình này.

Định lý 4.25. Nếu $y_1, y_2$ là hai nghiệm độc lập tuyến tính của phương trình (4.16) thì nghiệm tổng quát của (4.16) là

trong đó $C_1, \ C_2$ là các hằng số tùy ý.

$$
cũng là nghiệm của (4.16). Ngược lại, giả sử $y = C_1 y_1(x) + C_2 y_2(x)$ là một nghiệm của (4.16) với điều kiện ban đầu

$$
y_0 = y(x_0), \quad y'_0 = y'(x_0), \quad x_0 \in (a, b).
$$

Khi đó, ta có hệ phương trình

$$
\left\{ 
\begin{array}{ll}
C_1 y_1(x_0) + C_2 y_2(x_0) = y_0, \\
C_1 y'_1(x_0) + C_2 y'_2(x_0) = y'_0.
\end{array} 
\right.
$$

Vì $y_1$ và $y_2$ độc lập tuyến tính trên $(a, b)$, theo định lý 4.24, nên determinant Wronski của hệ phương trình

$$
W(y_1(x_0), y_2(x_0)) = W(x_0) 
= \left| 
\begin{array}{cc}
y_1(x_0) & y_2(x_0) \\
y'_1(x_0) & y'_2(x_0)
\end{array} 
\right|
\neq 0.
$$

Như vậy, tồn tại duy nhất cặp số $(C_1, C_2)$ của hệ phương trình (4) sao cho $C_1 y_1 + C_2 y_2$ là nghiệm của phương trình (4.16). Định lý được chứng minh.

Định lý 4.26. Nếu đã biết một nghiệm riêng $y_{1}(x) \neq 0$ của phương trình tuyến tính thuần nhất (4.16), ta có thể tìm được một nghiệm riêng $y_{2}(x)$ của phương trình đó, độc lập tuyến tính với cùng dạng trong đó $y_{1}(x)$:

$$

$$

$$

là một phương trình tách biệt. Giải phương trình này được nghiệm

$$

Mà $z = u'$, nên ta có

$$

$$

là điều phải chứng minh.

Định lý dưới đây sẽ đưa việc giải phương trình (4.15) về việc giải phương trình (4.16) và tìm một nghiệm riêng của nó.

Định lý 4.27. Nghiệm tổng quát của phương trình không thuần nhất (4.15) bằng nghiệm tổng quát $y$ của phương trình thuần nhất (4.16) cộng với một nghiệm riêng nào đó $y_{0}$ của nó.

\end{array}

ở đây $y = y + y_{0}$. Vậy $y$ là nghiệm của phương trình (4.15). Vì $y$ là nghiệm tổng quát của (4.16), nên $y$ phụ thuộc vào $C_{1}, C_{2}$. Bằng cách làm tương tự như trong chứng minh của định lý 4.25, ta có $y = \bar{y} + y_{0}$ là nghiệm tổng quát của phương trình (4.15).

Định lý 4.28. Cho phương trình

4.4. Hệ phương trình vi phân

# 4.4.1. Hệ phương trình vi phân cấp 1

Hệ $n$ phương trình vi phân cấp 1 có dạng:

$$
\left\{ \begin{array} { l l } { y _ { 1 } ^ { \prime } = f _ { 1 } ( x , y _ { 1 } , y _ { 2 } , . . . , y _ { n } ) , } \\ { y _ { 2 } ^ { \prime } = f _ { 2 } ( x , y _ { 1 } , y _ { 2 } , . . . , y _ { n } ) , } \\ { \quad } \\ { y _ { n } ^ { \prime } = f _ { n } ( x , y _ { 1 } , y _ { 2 } , . . . , y _ { n } ) , } \end{array} \right.
$$

được gọi là hệ chuẩn tắc, trong đó $x$ là biến độc lập và $y _ { 1 } , y _ { 2 } , . . . , y _ { n }$ là các hàm cần tìm. Bài toán Cauchy đối với hệ phương trình (4.23): Tìm các nghiệm ($y _ { 1 } = y _ { 1 } ( x ) , y _ { 2 } = y _ { 2 } ( x ) , . . . , y _ { n } = y _ { n } ( x )$) thỏa mãn điều kiện ban đầu:

$$
y _ { i } ( x _ { 0 } ) = y _ { 0 i } , \forall i = 1 , 2 , . . . , n ,
$$

trong đó $x _ { 0 } , y _ { 0 1 } , y _ { 0 2 } , . . . , y _ { 0 n }$ là những số cho trước. Tập hợp $n$ hàm số

$$
y _ { i } = y _ { i } ( x , C _ { 1 } , C _ { 2 } , . . . , C _ { n } ) , i = 1 , 2 , . . . , n ,
$$

trong đồ thị $C_1, C_2, \ldots, C_n$ là các hàm số tùy ý và $(x, y_1, y_2, \ldots, y_n) \in D$, được gọi là nghiệm tổng quát của hệ phương trình vi phân (4.23), nếu các hàm số trên thỏa mãn các điều kiện sau: Điều kiện 1: $y_i$ ($i = 1, 2, \ldots, n$) là nghiệm của (4.23) với mọi $C_1, C_2, \ldots, C_n$. Điều kiện 2: Với mỗi điểm $(x_0, y_{01}, y_{02}, \ldots, y_{0n}) \in D$, hệ phương trình

$$
y_{0i} = y_i(x_0, C_1, C_2, \ldots, C_n), i = 1, 2, \ldots, n,
$$

giải ra đúng đối với các hằng số $C_1, C_2, \ldots, C_n$:

Định lý 4.35. Giả sử các hàm số $f_i(x, y, y_1, y_2, \ldots, y_n)$ và các đạo hàm riêng $\frac{\partial f_i}{\partial y_i}(x, y_1, y_2, \ldots, y_n) (i = 1, 2, \ldots, n)$ liên tục trên miền $D \subseteq \mathcal{R}^{n+1}, (x_0, y_{01}, y_{02}, \ldots, y_{0n}) \in D$. Khi đó, tồn tại một lân cận của điểm $x_0$ sao cho bài toán Cauchy có duy nhất một nghiệm.

\left\{ \begin{array} { l l } { ( - 1 - \lambda ) \alpha - 2 \beta = 0 , } \\ { 3 \alpha + ( 4 - 1 ) \beta = 0 } \end{array} \right. \Leftrightarrow \alpha + \beta = 0 .
$$

Lấy $\alpha = 1, \beta = - 1$. Khi đó, ta có các nghiệm riêng

$$
x _ { 1 } = e ^ { t } , y _ { 1 } = - e ^ { t } .
$$

$+ \ \mathrm { V } \widetilde { \mathrm { O i } } \ \lambda _ { 2 } = 2$, tương tự ta có các nghiệm riêng

Vậy nghiệm tổng quát của hệ là

$$
\left\{ 
\begin{array} { l }
x = C _ { 1 } e ^ { t } + 2 C _ { 2 } e ^ { 2 t } \\
y = - C _ { 1 } e ^ { t } - 3 C _ { 2 } e ^ { 2 t }
\end{array} 
\right.
$$

trong đó $C _ { 1 } , C _ { 2 }$ là các hàng số bất kỳ.
