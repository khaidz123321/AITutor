$$
\begin{array}{l}

Bài 1.9. Tìm giá trị lớn nhất và nhỏ nhất của hàm số

a) $z = x ^ { 2 } + y ^ { 2 } - 2 x ^ { 2 } y + 1$ trên miền $D = \{ ( x , y ) : \ x ^ { 2 } + y ^ { 2 } \leq 1 \} .$

$$
\begin{array}{l}
\displaystyle \left\{ z _ { y } ^ { \prime } = 0 \right. \quad \Leftrightarrow ( x , y ) = ( 0 , 0 ) , \left( \frac { \sqrt { 2 } } { 2 } , \frac { 1 } { 2 } \right) , \left( - \frac { \sqrt { 2 } } { 2 } , \frac { 1 } { 2 } \right). \\
\displaystyle x ^ { 2 } + y ^ { 2 } \leq 1
\end{array}
$$

Tại biên $x ^ { 2 } + y ^ { 2 } = 1$, ta có $z ( x , y ) = f ( y ) = 2 ( y ^ { 3 } - y + 1 )$ với $| y | \leq 1$

$$
f ( - 1 ) = f ( 1 ) = 2, \quad f \left( \frac { \sqrt { 3 } } { 3 } \right) = 2 \left( 1 + \frac { \sqrt { 3 } } { 3 } \right), \quad f \left( - \frac { \sqrt { 3 } } { 3 } \right) = 2 \left( 1 - \frac { \sqrt { 3 } } { 3 } \right).
$$

Vậy hàm số đạt nhỏ nhất là $2 \left( 1 - \frac { \sqrt { 3 } } { 3 } \right)$ và lớn nhất là $2 \left( 1 + \frac { \sqrt { 3 } } { 3 } \right)$.
