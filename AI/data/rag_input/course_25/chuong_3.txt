# 3.1. Tích Phân Xác Định

# 3.1.1. Định Nghĩa

Cho hàm số $f ( x )$ xác định trên $[ a , b ]$

+ **Phép** chia $P$ đoạn $[ a , b ]$ (hay còn gọi là phân hoạch) bằng $n$ điểm

$$
x _ { 0 } = a < x _ { 1 } < \ldots < x _ { n } = b .
$$

Đặt $\Delta _ { x _ { i } } = x _ { i } - x _ { i - 1 } \ \forall i = 1 , 2 , . . . , n , \Delta _ { P } = \operatorname*{max} \{ \Delta _ { x _ { 1 } } , \Delta _ { x _ { 2 } } , . . . , \Delta _ { x _ { n } } \}$ (được gọi là độ dài của phân hoạch $P$）

Khi đó

$$
\sigma _ { n } = \sum _ { k = 1 } ^ { n } f ( \xi _ { k } ) \Delta _ { x _ { i } }
$$

được gọi là một tổng tích phân (hay còn gọi là tổng Riemann) của $f ( x )$ trên $[ a , b ]$. Xét giới hạn

$$
\quad I = \operatorname*{lim} _ { \Delta _ { P } \to 0 } \sigma _ { n } .
$$

Nếu $I$ tồn tại hữu hạn, không phụ thuộc vào phép chia $P$ và phép chọn các điểm $\xi _ { i } \ i = 1 , 2 , . . . , n .$ thì $\boldsymbol{ I }$ được gọi là tích phân xác định của $f ( x )$ trên $[ a , b ]$ và được ký hiệu $\textstyle \int f ( x ) d x$. Khi đó hàm số $f ( x )$ được gọi là khả tích trên $[ a , b ]$：

Trong trường hợp đặc biệt, phép chia $P$ đoạn $[ 0 , 1 ]$ bằng $n$ điểm cách đều nhau

$$
0 < \frac { 1 } { n } < \frac { 2 } { n } < \ldots < \frac { n } { n } = 1 .
$$

Với $f ( x )$ khả tích trên $[ 0 , 1 ]$, ta có

$$
\operatorname*{lim}_{n \to \infty} \frac{1}{n} \left( f\left(\frac{1}{n}\right) + f\left(\frac{2}{n}\right) + \ldots + f\left(\frac{n}{n}\right) \right) = \int_{0}^{1} f(x) dx.
$$

Ý nghĩa: Dùng tích phân để tính giới hạn.

Ví dụ 3.1. Giả sử $I = \int x^2 dx$ tồn tại. Dùng định nghĩa tích phân để tính I.

Giải Chia đoạn $[-1, 2]$ thành $n$ phần bằng nhau và chọn $\xi_i$ là mút bên trái của mỗi đoạn $[x_{i-1}, x_i]$, ta nhận được

$$
\sigma_P = \frac{3}{n} \sum_{k=1}^{n} \left( -1 + \frac{3(k-1)}{n} \right)^2 = \frac{3}{n} \sum_{k=1}^{n} \left( 1 - \frac{6(k-1)}{n} + \frac{9(k-1)^2}{n^2} \right)
$$

Vậy

$$
I = \int_{-1}^{2} x^2 dx = \operatorname*{lim}_{n \to \infty} \sigma_n = 3.
$$

## 3.1.2. Ý nghĩa hình học

Nếu $f(x) \geq 0 \forall x \in [a, b]$, thì $\sigma_n$ là tổng diện tích các hình chữ nhật có kích thước $\Delta_{x_i}$ và $f(\xi_i)$ $\forall i = 1, 2, ..., n$. Khi $\Delta_P$ đủ nhỏ, $\sigma_n$ gần đúng với diện tích hình thang cong tạo bởi các đường $x=a$, $x=b$, $Ox$ và $y=f(x)$.

Giả sử $f ( x )$ xác định và bị chặn trên $[ a , b ]$. Khi đó, tồn tại

$$
m _ { i } = \operatorname * { inf } _ { x \in [ x _ { i - 1 } , x _ { i } ] } f ( x ) , \quad M _ { i } = \operatorname * { sup } _ { x \in [ x _ { i - 1 } , x _ { i } ] } f ( x ) \forall i = 1 , 2 , . . . , n .
$$

Ta gọi

$$
s _ { P } = \sum _ { k = 1 } ^ { n } m _ { i } \Delta _ { x _ { i } }
$$

là tổng Darboux dưới của hàm $f ( x )$ trên $[ a , b ]$ và

$$
S _ { P } = \sum _ { k = 1 } ^ { n } M _ { i } \Delta _ { x _ { i } }

$$

# 3.3.3. Công thức Newton-Leibnitz

Với mỗi $F(x)$ xác định trên $[a, b]$, ta ký hiệu

$$
F(b) - F(a) = F(x) \Big|_a^b.
$$

Định lý 3.11. (Công thức Newton-Leibnitz)

Nếu $f(x)$ liên tục trên $[a, b]$ và $F(x)$ là một nguyên hàm của $f(x)$, thì

$$
\int_a^b f(x) dx = F(x) \Big|_a^b.
$$

Chứng minh Theo định lý 3.10, $\varphi(x) = \int f(t) dt$ là một nguyên hàm của $f(x)$: a Theo định lý 3.9, tồn tại $\mathbf{s} \in [a, b]$ sao cho $\varphi(x) = F(x) + C \forall x \in [a, b]$. Vì

$$
\varphi(a) = F(a) + C = 0 \Rightarrow C = -F(a),
$$

nên

$$
\int_a^b f(x) dx = \varphi(b) = F(b) + C = F(b) - F(a).
$$

# 3.7.3. Tính thể tích của vật thể

Cho vật thể $(H)$ nằm giữa hai mặt phẳng vuông góc với $Ox$

$$

Khi đó với mỗi $x_0 \in [a, b]$, mặt phẳng $(\gamma)$ có phương trình $x = x_0$ cắt vật thể $(H)$ theo thiết diện có diện tích $S(x_0)$. Khi đó thể tích vật thể $(H)$ được tính bằng công thức

$$

$$

$$
\left\{

x = b.
\end{array} 
\right.
$$

# 3.8.1. Định nghĩa

Cho hàm $f ( x )$ khả tích trên $[ a , b ] \forall b > a$. Nếu tồn tại hữu hạn giới hạn

$$
\operatorname*{lim}_{b \to +\infty} \int_{a}^{b} f(x) dx,
$$

thì giới hạn này được gọi là tích phân suy rộng của hàm số $f ( x )$ với $\mathrm{cận} +\infty$ và ký hiệu là

$$
\int_{a}^{+\infty} f(x) dx.
$$

Khi tích phân hội tụ, ta nói rằng tích phân hội tụ. Ngược lại, tích phân suy rộng trên là phần kỳ.

Tương tự như vậy, ta định nghĩa tích phân suy rộng với cận $-\infty$

$$
\operatorname*{lim}_{a \to -\infty} \int_{a}^{b} f(x) dx = \int_{-\infty}^{b} f(x) dx.
$$

Tích phân suy rộng của hàm số $f ( x )$ với hai cận $+\infty, -\infty$, ký hiệu là $\int_{-\infty}^{+\infty} f(x) dx$. Tích phân này hội tụ khi và chỉ khi cả hai tích phân suy rộng

$$
\int_{a}^{+\infty} f(x) dx, \int_{-\infty}^{b} f(x) dx \forall a , b \in \mathbb{R}
$$

cũng hội tụ. Khi đó

$$
\int_{-\infty}^{+\infty} f(x) dx = \int_{a}^{+\infty} f(x) dx + \int_{-\infty}^{a} f(x) dx \forall a \in \mathbb{R}.
$$

$$

ii) Cho tích phân
$$
I_2 = \int_{1}^{+\infty} \frac{\sin x}{x} dx.
$$

Chứng minh rằng: $I_2$ hội tụ.

Giải:
i) Ta có
$$
0 \leq \frac{|\cos x|}{x^2} \leq \frac{1}{x^2} \forall x \geq 1 \text{ và } \int_{1}^{+\infty} \frac{1}{x^2} dx = 1.
$$

Do đó $I_1$ hội tụ (Theo định lý 3.39).

ii) $I_2$ hội tụ.

Thật vậy,
$$
I_2 = \int_{1}^{+\infty} \frac{\sin x}{x} dx = \int_{1}^{+\infty} \frac{1}{x} d(-\cos x) = -\frac{\cos x}{x}\Big|_{1}^{+\infty} + \int_{1}^{+\infty} \frac{-1}{x^2} \cos x dx.
$$

Mà $\lim_{x \to +\infty} \frac{1}{x} \cos x = 0$ và theo i), 
\[ I_1 = \int_1^{+\infty} \frac{\cos x}{x^2} dx \]
hội tụ. Do vậy $I_2$ hội tụ.

$I_2$ không hội tụ tuyệt đối.

Thật vậy, từ bất đẳng thức

\[
\left| \frac{\sin x}{x} \right| \geq \frac{\sin^2 x}{x} ~ \forall x \geq 1,
\]

ta xét tích phân 
\[ J = \int_1^{+\infty} \frac{\sin^2 x}{x} dx. \]

\[
J = \int_{1}^{+\infty} \frac{1 - \cos 2x}{2x} dx = \frac{1}{2} \int_{1}^{+\infty} \frac{1}{x} dx - \int_{1}^{+\infty} \frac{\cos 2x}{2x} dx.
\]

Tương tự như $I_2$ a $\mathrm{d}$ dạng chứng minh được 
\[ \int_{1}^{+\infty} \frac{\cos 2x}{2x} dx \]
hội tụ. Từ

\[
\int \frac{1}{x} dx = \lim_{b \to +\infty} \ln x \Big|_1^b = +\infty
\]

suy ra $J = +\infty$. Hay 
\[ \int_1^{+\infty} \left| \frac{\sin x}{x} \right| dx \]
phần kỳ. Vậy $I_2$ không hội tụ tuyệt đối.

# 3.9. Tích phân suy rộng với cấp hữu hạn

## 3.9.1. Định nghĩa

$^+$ Cho hàm số $f(x)$ khả tích trên $[a,c] \ \forall c \in (a,b)$ và $\operatorname*{lim}_{x \to b^{-}} f(x) = \infty$. Khi đó

$$
I = \operatorname*{lim}_{c \to b^{-}} \int_{a}^{c} f(x) dx
$$

được gọi là tích phân suy rộng với cực điểm $b$ và ký hiệu là $\begin{array}{l}
\quad {b}\\
{\int f(x)dx. \text{Nếu } I}\\
{a}
\end{array}$ tồn tại hữu hạn, thì $\stackrel{b}{\int} f(x) dx$ được gọi là hội tụ. Ngược lại, gọi là phân kỳ.

$^+$ Cho hàm số $f(x)$ khả tích trên $[c,b] \forall c \in (a,b)$ và $\operatorname*{lim}_{x \to a^{+}} f(x) = \infty$. Khi đó

$$
I = \operatorname*{lim}_{c \to a^{+}} \int_{c}^{b} f(x) dx
$$

được gọi là tích phân suy rộng với cực điểm $a$ và ký hiệu là $\begin{array}{l}
\quad {b}\\
{\int f(x)dx. \text{Nếu } I}\\
{a}
\end{array}$ tồn tại hữu hạn, thì $\stackrel{b}{\int} f(x) dx$ được gọi là hội tụ. Ngược lại, gọi là phân kỳ.

U $+$ Cho hàm số $f ( x )$ khả tích trên $[ c , b ] \forall c \in ( x _ { 0 } , b )$, và $[ a , c ] \forall c \in ( a , x _ { 0 } )$ và $\operatorname*{lim}_{x \to x_{0}} f(x) = +\infty$. Khi đó $\int_a^b f(x)\,dx$ được gọi là tích phân suy rộng với cực điểm $x_0$. Nếu $\int_a^{x_0} f(x)\,dx$ và $\int_{x_0}^b f(x)\,dx$ hội tụ, thì $\int_a^b f(x)\,dx$ được gọi là hội tụ. Ngược lại, gọi là phân kỳ.

$+$ Cho hàm số $f ( x )$ khả tích trên $[ c , b ] \forall b > c > a$ và $\operatorname*{lim}_{c \to a^{+}} f(x) = +\infty$. Khi đó $\int_a^b f(x)\,dx$ được gọi là tích phân suy rộng với cực điểm $x_0$ và cần vô hạn. Nếu 
$\int_{a}^{b} f(x)\,dx$ hội tụ, thì $\int_{a}^{b} f(x)\,dx$ được gọi là hội tụ. Ngược lại, gọi
là phân kỳ.

Ví dụ 3.41. Tính tích phân suy rộng

$$
\int \limits _ { a } ^ { b } \frac { d x } { ( x - a ) ^ { \alpha } } ( a < b , \alpha \in \mathbb{R} ).
$$

Giải Nếu $\alpha > 0$, thì $\operatorname*{lim}_{x \to a^{+}} \frac{1}{(x-a)^{\alpha}} = +\infty \Rightarrow x = a$ là cực điểm. Ta xét các trường hợp sau:

$+$ Nếu $\alpha > 1$, thì

$$
\int _ { \imath } ^ { b } \frac { d x } { ( x - a ) ^ { \alpha } } = \int _ { a } ^ { b } ( x - a ) ^ { - \alpha } d ( x - a ) = \frac { 1 } { ( 1 - \alpha ) ( x - a ) ^ { \alpha - 1 } } \Big | _ { a } ^ { b } = + \infty .
$$

+ Nếu $\alpha = 1$, thì

$$
\int _ { a } ^ { b } \frac { d x } { x - a } = \ln ( x - a ) \Big| _ { a } ^ { b } = + \infty .
$$

+ Nếu $\alpha < 1$, thì

$$
\int _ { a } ^ { b } \frac { d x } { ( x - a ) ^ { \alpha } } = \int _ { a } ^ { b } ( x - a ) ^ { - \alpha } d ( x - a ) = \frac { 1 } { 1 - \alpha } ( x - a ) ^ { 1 - \alpha } \bigg| _ { a } ^ { b } = \frac { 1 } { ( 1 - \alpha ) ( b - a ) ^ { 1 - \alpha } } .
$$

Như vậy

$$
\int _ { a } ^ { b } \frac { d x } { ( x - a ) ^ { \alpha } } = \left\{ \begin{array} { l l } { + \infty } & { \text{nếu } \alpha \geq 1 } \\ { \frac { 1 } { ( 1 - \alpha ) ( b - a ) ^ { 1 - \alpha } } } & { \text{nếu } \alpha < 1 . } \end{array} \right.
$$

# 3.9.2. Quan hệ giữa hai loại tích phân suy rộng

Xét tích phân suy rộng với cận hữu hạn có cực điểm $a$

$$
\int _ { a } ^ { b } f ( x ) d x .
$$

Đổi biến $\begin{array} { r } { x = a + \frac { 1 } { y }, \quad y \to + \infty } \end{array}$, ta có

$$
\quad : x = \operatorname*{lim}_{c \to a^+} \int f(x) dx = \operatorname*{lim}_{y \to +\infty} \int f(a + \frac{1}{y}) \frac{-dy}{y^2} = \operatorname*{lim}_{y \to +\infty} \int_{\frac{1}{b-a}}^{y} \frac{f(a + \frac{1}{y})}{y^2}
$$

Nhu vậy

$$
\int_a^b f(x) dx = \int_\alpha^{+\infty} g(x) dx \quad \text{với } g(x) = \frac{f(a + \frac{1}{x})}{x^2}, \alpha = \frac{1}{b-a}.
$$

3.9.3. Các định lý hội tụ

Tương tự như chứng minh đối với tích phân suy rộng với cận vô hạn. Ta có các định lý dưới đây.

Định lý 3.42. (Đầu hiệu so sánh)

Cho các hàm $f, g \quad 0 \leq f(x) \leq g(x) \forall x \in [a,b)$ và $\operatorname*{lim}_{x \to b^+} f(x) = \operatorname*{lim}_{x \to b^+} g(x) = +\infty$. Khi đó.

- Nếu $\int_a^b g(x) dx$ hội tụ, thì $\int_a^b f(x) dx$ hội tụ.
- Nếu $\int_a^b f(x) dx$ phân kỳ, thì $\int_a^b g(x) dx$ phân kỳ.

Ví dụ 3.43. Khảo sát sự hội tụ của tích phân

$$
I = \int_0^1 \frac{|\ln x|}{x^\alpha} dx \quad (\alpha \in \mathbb{R}).
$$

Giải Trường hợp $\boldsymbol{I}$. Nếu $\alpha < 1$, Đặt $\epsilon = 1 - \alpha$, khi đó $\epsilon > 0$. Ta có

$$
\frac { | \ln x | } { x ^ { \alpha } } = \frac { | \ln x | } { x ^ { 1 - \epsilon } } = \frac { x ^ { \frac { \epsilon } { 2 } } | \ln x | } { x ^ { 1 - \frac { \epsilon } { 2 } } } .
$$

Vì $\lim_{x \to 0^+} x ^ { \frac { \epsilon } { 2 } } | \ln x | = 0$ suy ra tồn tại $x _ { 0 }$ sao cho

$$
\left. x ^ { \frac { \epsilon } { 2 } } \right| \ln x | < 1 \forall x \in ( 0 , x _ { 0 } ) .
$$

Vậy

$$
\frac { | \ln x | } { x ^ { \alpha } } = \frac { x ^ { \frac { \epsilon } { 2 } } | \ln x | } { x ^ { 1 - \frac { \epsilon } { 2 } } } < \frac { 1 } { x ^ { 1 - \frac { \epsilon } { 2 } } } . \forall x \in ( 0 , x _ { 0 } ) .
$$

Theo ví dụ 3.41, ta có $\int \limits _ { 0 } ^ { 1 } \frac { 1 } { x ^ { 1 - \frac { \epsilon } { 2 } } } d x$ hội tụ. Khi đó, theo định lý 3.42, tích phân $I$ hội tụ.

Định lý 3.44. (Đấu hiệu giới hạn)

Cho các hàm số $0 \leq f(x), 0 \leq g(x) \forall x \in [a,b)$, $\lim_{x \to b^+} f(x) = \lim_{x \to b^+} g(x) = +\infty$.

Nếu

$$
\lim_{x \to b^+} \frac{f(x)}{g(x)} = M \geq 0,
$$

khi đó

b $\underset { a } { \overset { b } { \mathop { \int } } } g(x) dx h \underset { \cdot } { \hat { \varrho } } i \underset { \cdot } { \overset { \quad } { \boldsymbol { t u . } } }$

- Nếu $M \in (0, +\infty)$ thì $\int f(x) dx$ hội tụ khi và chỉ khi $\int_a^b g(x)dx$ hội tụ. 

- Nếu $M = 0$ và $\int_a^b g(x)dx$ hội tụ, thì $\int_a^b f(x)dx$ hội tụ.

- Nếu $M = +\infty$ và $\int_a^b g(x)dx$ phân kỳ, thì $\int_a^b f(x)dx$ phân kỳ.

Vi dụ 3.45. Khảo sát sự hội tụ của các tích phân sau

$$
\begin{array} { r l }
& I _ { 1 } = \displaystyle \int _ { 0 } ^ { 1 } \frac { d x } { \sqrt { ( 1 - x ^ { 2 } ) ( 1 - k ^ { 2 } x ^ { 2 } ) } } ~ \nu o t ~ | k | < 1 . \\
& I _ { 2 } = \displaystyle \int _ { 0 } ^ { 1 } \frac { d x } { \sqrt [ 3 ] { x ( e ^ { x } - e ^ { - x } ) } } . \\
& I _ { 3 } = \displaystyle \int _ { 0 } ^ { \frac { \pi } { 2 } } \frac { \ln ( \sin x ) } { \sqrt { x } } d x .
\end{array}
$$

Giải

- Xét $I _ { 1 }$

Do $| k | < 1$ nên $1 - k ^ { 2 } x ^ { 2 } > 0 \forall x \in [ 0 , 1 ]$. Xét giới hạn

$$
\operatorname*{lim}_{x \to 1^-} \frac { 1 } { \sqrt { ( 1 - x ^ { 2 } ) ( 1 - k ^ { 2 } x ^ { 2 } ) } } = + \infty .
$$

Vậy $x = 1$ là cực điểm.

Đặt

$$
f(x) = \frac { 1 } { \sqrt { ( 1 - x ^ { 2 } ) ( 1 - k ^ { 2 } x ^ { 2 } ) } }, g(x) = \frac { 1 } { 1 - x } = \frac { 1 } { ( 1 - x ) ^ { \frac { 1 } { 2 } } }
$$

$$
\lim_{x \to 1^-} \frac{f(x)}{g(x)} = \lim_{x \to 1^-} \frac{1}{\sqrt{(1 + x)(1 - k^2 x^2)}} = \frac{1}{\sqrt{2(1 - k^2)}} \in (0, +\infty).
$$

Theo ví dụ 3.41, 
\[ \int \frac{dx}{\sqrt{1 - x}} = \hat{\mathrm{H}}_0(x) \quad \text{tại} \quad x=0. \]
Khi đó, theo định lý 3.44, $I_1$ hội tụ.

Xét $I_2$: 

Xét giới hạn
$$
\lim_{x \to 0^+} \frac{1}{\sqrt[3]{x(e^x - e^{-x})}} = \lim_{x \to 0^+} \sqrt[3]{\frac{e^x}{x(e^{2x} - 1)}} = +\infty.
$$

Đặt $g(x) = \frac{1}{\sqrt[3]{x^2}}$ suy ra
$$
\lim_{x \to 0^+} \frac{f(x)}{g(x)} = \frac{1}{\sqrt[3]{2}} \in (0, +\infty).
$$

Mà 
\[ \int_0^1 g(x) dx = 3. \]
Hội tụ. Vậy $\mathcal{I}_2$ hội tụ.

Xét $I_3$: 

Đặt $x = 0$ là cực điểm. Đặt
$$
f(x) = \frac{\ln(\sin x)}{\sqrt{x}}, \quad g(x) = \frac{1}{x^\lambda} \text{ với } \lambda \in \left( \frac{1}{2}, 1 \right).
$$

Theo quy tắc L'Hôpital, ta có

$$
\begin{array} { l } { \displaystyle \lim_{x \to 0^+} \frac { f ( x ) } { g ( x ) } = \displaystyle \lim_{x \to 0^+} \frac { \ln ( \sin { x } ) } { x ^ { \frac { 1 } { 2 } - \lambda } } } \\ { = \displaystyle \lim_{x \to 0^+} \frac { \cot x } { ( \frac { 1 } { 2 } - \lambda ) x ^ { - \frac { 1 } { 2 } - \lambda } } } \\ { = \displaystyle \lim_{x \to 0^+} \frac { x ^ { \frac { 1 } { 2 } + \lambda } } { ( \frac { 1 } { 2 } - \lambda ) \tan x } } \\ { = \displaystyle \lim_{x \to 0^+} \frac { x ^ { \frac { 1 } { 2 } + \lambda } } { ( \frac { 1 } { 2 } - \lambda ) x } } \\ { = 0 . } \end{array}
$$

Theo ví dụ 3.41, $\begin{array} { l } { \mathbf{\Lambda}_{0}^{1} \qquad \quad \overset{}{\int} g ( x ) d x } \\ { 0 \qquad \quad \qquad \quad ~ } \end{array}$ hội tụ, nên $I _ { 3 }$ hội tụ.
