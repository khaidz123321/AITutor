# CHUONG 1. SỐ THỰC, SỐ PHỨC VÀ GIỚ HẠN CỦA DÃY SỐ

# 1.1. Số thực

## 1.1.1. Mở đầu

Nhắc lại một số tập hợp quen thuộc:

+ Tập các số tự nhiên
$$
\mathbb{N} = \{0, 1, 2, \ldots\}.
$$

+ Tập các số nguyên
$$
\mathbb{Z} = \{0, \pm 1, \pm 2, \ldots\}.
$$

+ Tập các số hữu tỉ
$$
\mathbb{Q} = \left\{\frac{p}{q} : p \in \mathbb{Z}, q \in \mathbb{N} \backslash \{0\}\right\}.
$$

Ta có $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q}$.

Trong tập các số hữu tỉ $\mathbb{Q}$ có thể thực hiện các phép toán cộng, trừ, nhân và chia cho số khác 0. Trong $\mathbb{Q}$ còn có quan hệ thứ tự $\leq, \geq, =$. Theo ngôn ngữ đại số, $\mathbb{Q}$ cùng với các phép toán và quan hệ thứ tự đã cho là một trường được sắp xếp thứ tự.

Tuy nhiên, từ lâu người ta đã thấy tập $\mathbb{Q}$ chưa đầy đủ. Chẳng hạn, không có số hữu tỷ nào biểu diễn độ dài đường chéo của một hình vuông có cạnh bằng 1 đơn vị, biểu diễn số $\pi$ là tỉ số giữa độ dài của một đường tròn và đường kính của nó.

Một số hữu tỷ $x$, bằng cách viết $\textstyle x = \frac{p}{q}$ với $p, q \in \mathbb{Z}, q \neq 0$ và thực hiện phép chia $p$ cho $q$, ta có thể dừng lại với dãy sau đây sẽ được gọi là số thập phân:

$$
x = x_0 , x_1 x_2 \ldots
$$

trong đó $x_0 \in \mathbb{Z}$ và $x_1, x_2, \ldots \in \{ 0, 1, 2, \ldots, 9 \}$. Số thập phân này hoặc hữu hạn, tức là tồn tại $\mathbf{s} \geq 0$ sao cho $x_n = 0 \forall n > k$ hay

$$
x = x_0 , x_1 x_2 \ldots x_k ,
$$

hoặc vô hạn tuần hoàn với chu kỳ $p$, tức là

$$
x = x_0 , x_1 x_2 \ldots x_k \underbrace{x_{k+1} x_{k+2} \ldots x_{k+p}}_{p} \underbrace{x_{k+1} x_{k+2} \ldots x_{k+p}}_{p} \cdots \underbrace{x_{k+1} x_{k+2} \ldots x_{k+p}}_{p}.
$$

Hiển nhiên

$$
x = x_0 + \frac{x_1}{10} + \ldots + \frac{x_k}{10^k},
$$

hoặc

$$
x = x_{0} + \frac{x_{1}}{10} + \ldots + \frac{x_{y}}{10^{k}} + x_{k_{1}} x_{k_{2}} \ldots x_{k_{p}} . \frac{1}{10^{k}(1 - 10^{-p})}.
$$

Ngược lại, mỗi số thập phân hữu hạn hay vô hạn tuần hoàn đều được biểu diễn dưới dạng một số hữu tỷ. Như vậy, ta có thể đồng nhất tập các số hữu tỷ $\mathbb{Q}$ với tập các số thập phân hữu hạn hay vô hạn tuần hoàn.

Một cách tổng quát, ta coi mỗi số thập phân vô hạn không tuần hoàn là một số mới và gọi là số vô tỷ. Tập các số hữu tỷ và vô tỷ gọi là tập các số thực, ký hiệu là $\mathbb{R}$. Mỗi phần tử của $\mathbb{R}$ được gọi là một số thực.

Cho số thực

Khi đó

$x_{0}$ được gọi là phần nguyên của $x$, ký hiệu là $[x]$

$x_{n}$ được gọi là phần thập phân thứ $n$ của $x$:

Nếu tồn tại số nguyên $m$ sao cho

$$
m \leq x < m + 1
$$

thì $m$ được gọi là sàn của $x$, ký hiệu $\lfloor x \rfloor$

Nếu tồn tại số nguyên $m$ sao cho

$$
m - 1 < x \leq m
$$

thì $m$ được gọi là trần của $x$, ký hiệu $\lceil x \rceil$:

Giả sử $x, y \in \mathbb{R}$

$$
x = x_{0}, x_{1} x_{2} \ldots \quad \text{và} \quad y = y_{0}, y_{1} y_{2} \ldots
$$

Ta viết $x < y$ nếu $x_{0} < y_{0}$ hay tồn tại $k$ sao cho $x_{0} = y_{0}, \ldots, x_{k} = y_{k}$ và $x_{k+1} < y_{k+1}$. Hai số bằng nhau $x = y$ nếu $x_{i} = y_{i} \forall i = 0, 1, \ldots$

# 1.1.2. Các tính chất của tập số thực

+ Tính sắp thứ tự

Cho hai số thực $a, b$. Khi đó, $a$ và $b$ so sánh được với nhau, tức là $a \leq b$ hoặc $a > b$. Vậy, giả sử $a = a_0, a_1 a_2 ...$, $b = b_0, b_1 b_2 ...$. Nếu $a \neq b$ thì tồn tại $k \in \mathbb{N}$ sao cho

$$
a_0 = b_0, ..., a_k = b_k
$$

nhưng

$$
a_{k+1} < b_{k+1} \text{ hay } a_{k+1} > b_{k+1}.
$$

Như vậy $a < b$ hoặc $a > b$.

+ Tính trù mật

Cho 2 số thực $a, b$ và $a < b$. Tồn tại số hữu tỷ $r \in \mathbb{Q}$ sao cho $a < r < b$. Vậy, giả sử $a = a_0, a_1 a_2 ...$, $b = b_0, b_1 b_2 ...$, từ $a < b$ suy ra tồn tại $k \in \mathbb{N}$ sao cho

$$
a_0 = b_0, ..., a_k = b_k, a_{k+1} < b_{k+1}.
$$

Khi đó, ta chọn số hữu tỷ là

$$
r = \left\{
\begin{array}{ll}
a_0, a_1 ... a_k b_{k+1} & \text{nếu } b \in \mathbb{Q} \\
\frac{1}{2}(a_0, a_1 ... a_k a_{k+1} + a_0, a_1 ... a_k b_{k+1}) & \text{nếu } b \notin \mathbb{Q}
\end{array}
\right.
$$

thỏa mãn $a < r < b$.

+ Tính đày đủ

Cho $A \subseteq \mathbb{R}$. Khi đó

$m \in \mathbb{R}$ được gọi là can dưới của $A$ nếu $m \leq a \forall a \in A$. Nếu $m$ là can dưới lớn nhất trong các can dưới của $A$ thì $m$ được gọi là can dưới đúng của $A$, ký hiệu $m = \operatorname{inf} A.$

$M \in \mathbb{R}$ được gọi là can trên của $A$ nếu $a \leq M \forall a \in A$. Nếu $M$ là can trên nhỏ nhất trong các can trên của $A$ thì $M$ được gọi là can trên đúng của $A$, ký hiệu $M = \operatorname{sup} A.$

Theo tính sắp thứ tự của tập số thực, nên nếu tồn tại thì $\sup A$, $\inf A$ là duy nhất. Tính tồn tại được thừa nhận bởi nguyên lý dưới đây.

Định lý 1.1. Mỗi tập con khác rỗng của tập số thực $\mathbb{R}$ có ít nhất một can trên (tương ứng một can dưới) thì tồn tại duy nhất can trên đúng (tương ứng can dưới đúng).

Chú ý rằng tập các số hữu tỉ $\mathbb{Q}$ không có tính đầy đủ. Ví dụ trong $\mathbb{Q}$ có tập $A = \{ x : \ x^2 < 2 \}$ không có can trên đúng trong $\mathbb{Q}$.

+ Các tập số thực thông dụng.

- Đoạn trên $\mathbb{R}$
$$
[a, b] = \{ x \in \mathbb{R} : a \leq x \leq b \}.
$$

- Nửa đoạn trên $\mathbb{R}$
$$
[a, b) = \{ x \in \mathbb{R} : a \leq x < b \}, [a, +\infty) = \{ x \in \mathbb{R} : a \leq x \}.
$$

- Nửa khoảng trên $\mathbb{R}$
$$
(a, b] = \{ x \in \mathbb{R} : a < x \leq b \}, (-\infty, b] = \{ x \in \mathbb{R} : x \leq b \}.
$$

- Khoảng trên $\mathbb{R}$

$$
( a , b ) = \{ x \in \mathbb { R } : \ a < x < b \} , \mathbb { R } = ( - \infty , + \infty ) .
$$

- Cho $a \in \mathbb { R }$ và $\epsilon > 0$, khoảng

$$
( a - \epsilon , a + \epsilon ) = \{ x \in \mathbb { R } : | x - a | < \epsilon \} = B _ { \epsilon } ( a )
$$

được gọi là một lân cận của điểm $a$.

# 1.2. Số phức

# 1.2.1. Mở đầu

Tập số thực $\mathbb { R }$ đã rất phong phú, nhưng nếu ta xét phương trình bậc 2

$$
a x ^ { 2 } + b x + c = 0 ,
$$

đây $a \neq 0 , a , b , c \in \mathbb { R }$ với $\Delta : = b ^ { 2 } - 4 a c < 0$, thì phương trình sẽ vô nghiệm trên $\mathbb { R }$. Để mở rộng lớp nghiệm của phương trình này, ta mở rộng tập số thực thành tập số phức (ký hiệu: $\mathbb { C }$). Muốn xây dựng tập số phức, ta quan tâm đến số $i$ thỏa mãn $i ^ { 2 } = - 1$, số $i$ không phải là số thực và được gọi là đơn vị ảo.

# 1.2.2. Định nghĩa và các phép toán

· Tập số phức là một tập hợp xác định bởi

$$
\mathbb { C } : = \{ z = a + b i : \ a , b \in \mathbb { R }, i ^ { 2 } = - 1 \} .
$$

· Cho số phức $z := a + b i$ với $a, b \in \mathbb { R }$ (còn gọi là dạng chính tắc của $z$), khi đó $a$ được gọi là phần thực của $z$, ký hiệu tắt bởi $\mathrm{Re} z$ (Real of $z$).

· $b$ được gọi là phần ảo của $z$, ký hiệu tắt bởi $\mathrm{Im} z$ (Image of $z$).

· $\sqrt { a ^ { 2 } + b ^ { 2 }}$ được gọi là môđun (còn gọi là độ dài) của $z$, ký hiệu tắt bởi $| z |$.

. Số phức $a - b i$ được gọi là số phức liên hợp của số phức $z$, ký hiệu tắt bằng $\bar{z}$: Số phức $- a + b i$ được gọi là số phức đối của số phức $z$: 

（20）Cho 2 số phức dưới dạng chính tắc $x = x_{1} + x_{2} i, y = y_{1} + y_{2} i$. Các phép toán trên tập số phức $\mathbb{C}$ được xác định bằng các quy tắc sau:

- Quy tắc cộng: $x + y = (x_{1} + y_{1}) + (x_{2} + y_{2}) i.$
- Quy tắc trừ: $x - y = (x_{1} - y_{1}) + (x_{2} - y_{2}) i$
- Quy tắc nhân: $x . y = (x_{1} y_{1} - x_{2} y_{2}) + (x_{1} y_{2} + x_{2} y_{1}) i.$
- Quy tắc bằng nhau:
$$
x = y \Leftrightarrow { \left\{ \begin{array}{ll}
{x_{1} = y_{1}} \\
{x_{2} = y_{2}}
\end{array} \right. }
$$

1.2.3. Tính chất

a) Tính chất kết hợp (với phép cộng): $(x + y) + z = x + (y + z) \forall x, y, z \in \mathbb{C}.$
b) Tính chất kết hợp (với phép nhân): $(xy)z = x(yz) \forall x, y, z \in \mathbb{C}.$

c) Tính chất giao hoán: $x + y = y + x \forall x, y \in \mathbb{C}.$
d) Tính chất phân phối của phép nhân với phép cộng: $x(y + z) = xy + xz \forall x, y, z \in \mathbb{C}$.

e) $\overline{x \pm y} = \bar{x} \pm \bar{y} \quad \forall x, y \in \mathbb{C}.$

f) $\overline{x . y} = \bar{x} . \bar{y} \quad \forall x, y \in \mathbb{C}.$

g) $x . \bar{x} = |x|^2 \quad \forall x \in \mathbb{C}.$

h) $\overline{\left( \frac{x}{y} \right)} = \frac{\bar{x}}{\bar{y}} \quad \forall x, y \in \mathbb{C}, y \neq 0.$

i) $|x| \geq 0 \quad \forall x \in \mathbb{C}, |x| = 0 \Leftrightarrow x = 0.$

j) $|x . y| \leq |x| . |y| \quad \forall x, y \in \mathbb{C}.$

k) $|x + y| \leq |x| + |y| \quad \forall x, y \in \mathbb{C}.$

Chứng minh biểu diễn các số phức dưới dạng chính tắc và dùng định nghĩa 1.2.

Ví dụ 1.2. Giải và biện luận phương trình sau trên tập các số phức $\mathbb{C}$:

$$
a x^2 + b x + c = 0 \quad \text{với} \ a \neq 0.
$$

Giải

$\Delta := b^2 - 4ac.$

- Nếu $\Delta = 0$, thì phương trình có nghiệm kép $x_1 = x_2 = \frac{-b}{2a}$.

- Nếu $\Delta > 0$, thì phương trình có 2 nghiệm thực phân biệt:

$$
x_{1, 2} = \frac{-b \pm \sqrt{\Delta}}{2a}.
$$

- Nếu $\Delta < 0$, thì $\Delta = -(-\Delta) = (i \sqrt{-\Delta})^2$. Khi đó, phương trình có 2 nghiệm phức phân biệt:

$$
x_{1, 2} = \frac{-b \pm i \sqrt{-\Delta}}{2a}.
$$

Vi dụ 1.3. Cho số phức $\begin{array} { r } { z = \frac { a - b i } { a + b i } } \end{array}$ với $a , b \in \mathbb { R } , b \neq 0$. Hãy tính $Im(z), Re(z), |z|$:

Giải

Nhân cả tử và mẫu số với $a - bi$, ta có

$$
\begin{array} { l } { z = \cfrac { ( a - b i ) ^ { 2 } } { a ^ { 2 } - b ^ { 2 } i ^ { 2 } } } \\ { \displaystyle = \cfrac { a ^ { 2 } - b ^ { 2 } - 2 a b i } { a ^ { 2 } + b ^ { 2 } } } \\ { \displaystyle = \cfrac { a ^ { 2 } - b ^ { 2 } } { a ^ { 2 } + b ^ { 2 } } + \cfrac { - 2 a b } { a ^ { 2 } + b ^ { 2 } } . i } \end{array}
$$

Khi đó. $\begin{array} { r } { Re(z) = \frac { a ^ { 2 } - b ^ { 2 } } { a ^ { 2 } + b ^ { 2 } } , Im(z) = \frac { - 2 a b } { a ^ { 2 } + b ^ { 2 } } } \end{array}$ và $|z|=√Re^2(z)+Im^2(z)=1$.

Vi dụ 1.4. Bất đẳng thức Cauchy-Schwarz

Cho các số phức $a _ { 1 } , a _ { 2 } , . . . , a _ { n }$ và $b _ { 1 } , b _ { 2 } , . . . , b _ { n }$. Khi đó

$$
| \sum _ { i = 1 } ^ { n } a _ { i } . b _ { i } | ^ { 2 } \leq \sum _ { i = 1 } ^ { n } | a _ { i } | ^ { 2 } . \sum _ { i = 1 } ^ { n } | b _ { i } | ^ { 2 } .
$$

Chứng minh

Đặt

$$
a = \sum _ { i = 1 } ^ { n } | a _ { i } | ^ { 2 } , b = \sum _ { i = 1 } ^ { n } | b _ { i } | ^ { 2 } , c = \sum _ { i = 1 } ^ { n } a _ { i } . \bar{b _ { i }} .
$$

Nếu $b = 0$ thì $b _ { 1 } = b _ { 2 } = \ldots = b _ { n }$, bất đẳng thức luôn đúng. Nếu $b > 0$, theo tính chất 1.3.e) và $\mathbf{g}$, ta có

$$
\begin{array}{rl}
\displaystyle \sum_{i=1}^{n} |b . a _ { i } - c . b _ { i }|^2 &= \displaystyle \sum_{i=1}^{n} (b . a _ { i } - c . b _ { i }) (b . a _ { i } - c . b _ { i }) \\
&= \displaystyle \sum_{i=1}^{n} (b . a _ { i } - c . b _ { i }) (b . \bar{a} _ { i } - c . \bar{b} _ { i }) \\
&= b^2 \displaystyle \sum_{i=1}^{n} |a _ { i }|^2 - bc \sum_{i=1}^{n} a _ { i }. \bar{b} _ { i } - bc \sum_{i=1}^{n} \bar{a} _ { i }. b _ { i } + |c|^2 \sum_{i=1}^{n} | \\
&= b^2 . a - b|c|^2 \\
&= b (ab - |c|^2).
\end{array}
$$

Vì $b > 0$, nên $a . b - | c | ^ { 2 } \geq 0$

# 1.2.4. Biểu diễn hình học của số phức

Cho mặt phẳng tọa độ Descartes vuông góc (Oxy). Xét một ánh xạ

$$
f : \mathbb{C} \to (Oxy)
$$

$$
z = a + bi \mapsto f(z) = M(a; b) \in (Oxy)
$$

Ánh xạ $f$ là một sự tương ứng 1-1 (còn gọi là một song ánh) giữa tập số phức $\mathbb{C}$ và tập các điểm trên mặt phẳng tọa độ $(Oxy)$. Khi đó, mặt phẳng $(Oxy)$ còn được gọi là mặt phẳng phức.

Hình 1: Biểu diễn hình học của $z = a + bi$

Vi dụ 1.5. Cho \( z \in \mathbb{C} \) thỏa mãn \(\textstyle \frac{z^2}{z + i} \in i\mathbb{R}\). Hãy biểu diễn hình học của \( z \) trên mặt phẳng phức \((Oxy)\):

Giải

Giả sử \( z = x + yi \), khi đó

$$
\frac{z^2}{z + i} = \frac{z^2 (\bar{z} - i)}{|z + i|^2} = \frac{(x + yi)^2 (x - y(i+1))}{|z + i|^2}
$$

Giả thiết cho \(\textstyle \frac{z^2}{z + i} \in i\mathbb{R}\), điều này có nghĩa là \( \operatorname{Re} \left( \frac{z^2}{z + i} \right) = 0 \) hay

$$
(x + yi)^2 (x - y(i+1)) = 0 \quad \Rightarrow \quad x(x^2 - y^2 + 2xy(y+1)) = 0 \quad \Rightarrow \quad x(x^2 + y^2 + 2y) = 0
$$

Hay \( x = 0 \) hoặc \( x^2 + (y + 1)^2 = 1 \). Khi đó, điểm biểu diễn \( M(x, y) \) nằm trên trục \( Oy \) hoặc nằm trên đường tròn tâm \( I(0, -1) \) bán kính \( R = 1 \).

Đưa vào biểu diễn hình học của \( z \), ta có \( OM = \sqrt{x^2 + y^2} = |z| \) và

$$
\left\{
\begin{array}{l}
x = |z| \cos \varphi \\
y = |z| \sin \varphi 
\end{array}
\right.
$$

Do đó, số phức \( z \) có thể được viết lại là

$$
z = |z| (\cos \varphi + i \sin \varphi),
$$

trong đó \(\varphi\) gọi là Argumen của \( z \) và được ký hiệu bởi \( \operatorname{Arg}(z) \). Như vậy, với mỗi \( z \in \mathbb{C} \), ta có:

$$
\boxed{x = 0 \text{ hoặc } x^2 + (y+1)^2 = 1}
$$

$$
z = | z | . [ \cos \operatorname{Arg}(z) + i \sin \operatorname{Arg}(z) ]
$$

Biểu thức này được gọi là dạng lượng giác của $z$.

$\operatorname{Arg}(z)$ có một vài tính chất sau:

1) Nếu $\varphi$ là một Argumen của số phức $z$, thì $\varphi + k 2 \pi (k \in \mathbb{Z})$ cũng là Argumen của $z$. Như vậy $\operatorname{Arg}(z)$ có thể sai khác số lần $2\pi$:

$$
\operatorname{Arg}(\bar{z}) = -\operatorname{Arg}(z) \quad \forall z \in \mathbb{C}.
$$

Chứng minh Giả sử $z = |z| . (\cos \varphi + i \sin \varphi)$, theo định nghĩa của $\bar{z}$ ta có

$$
\bar{z} = |z| . (\cos \varphi - i \sin \varphi) = |z| . [\cos (-\varphi) + i \sin (-\varphi)].
$$

# 1.3. Dãy số thực

## 1.3.1. Các khái niệm cơ bản

-Một ánh xạ

$$
n \mapsto f ( n ) = x _ { n } ,
$$

Khi $\mathbb{K} = \mathbb{R}$, ta sẽ nhận được một dãy số thực, gọi tắt là dãy $(x_n)_{n=1}^{\infty}$ hay $(x_n)$ hay $(x_n)_{n \geq 0}$. Trong trường hợp $\mathbb{K} = \mathbb{C}$, $(x_n)$ được gọi là dãy số phức. Khi đó, $x_n$ được gọi là số hạng tổng quát thứ $n$ của dãy số $(x_n)$. Ví dụ: Dãy số $\left( \frac{1}{n} \right): \left\{ 1, \frac{1}{2}, \ldots, \frac{1}{n}, \ldots \right\}$.

Dãy số $\begin{array}{r}\left((1 + \frac{1}{n})^n\right): (1 + \frac{1}{1}), (1 + \frac{1}{2}), \ldots\end{array}$

-Dãy số $(x_n)$ gọi là bị chặn dưới, nếu tồn tại $m \in \mathbb{R}$ sao cho $m \leq x_n \forall n$.

-Dãy số $(x_n)$ gọi là bị chặn trên, nếu tồn tại $M \in \mathbb{R}$ sao cho $x_n \leq M \forall n$.

-Dãy số $(x_n)$ gọi là bị chặn, nếu dãy $(x_n)$ bị chặn dưới và bị chặn trên.

-Ta nói dãy số $(x_n)$ tiến đến $-\infty$, ký hiệu $\lim x_n = -\infty$ khi và chỉ khi $x_n \to -\infty$ khi $n \to \infty$.

-Ta nói dãy số $(x_n)$ tiến đến $+\infty$, ký hiệu $\lim x_n = +\infty$ khi và chỉ khi $x_n \to +\infty$ khi $n \to \infty$.

-Số $A$ được gọi là giới hạn của dãy số $(x_n)$ khi $n$ dần ra vô cùng, hay ta còn nói dãy số $(x_n)$ hội tụ đến $A$, ký hiệu $\lim_{n \to \infty} x_n = A$ khi và chỉ khi:

Vi dụ 1.15. Dùng định nghĩa, chứng minh rằng $\operatorname*{lim}_{n \to \infty} \frac{a}{n} = 0.$

Chứng minh:
- Nếu $a = 0$, thì kết luận trên đúng.
- Nếu $a \neq 0$, ta đặt $x_n = \frac{a}{n}, \forall \epsilon > 0$ và xét
$$
| x_n - 0 | = \frac{|a|}{n} < \epsilon \Leftrightarrow n > \frac{|a|}{\epsilon} \Rightarrow \text{chọn } n_0 = \left[ \frac{|a|}{\epsilon} \right] + 1.
$$
Thì lại định nghĩa:
$$
\exists n_0 = \left[ \frac{|a|}{\epsilon} \right] + 1, \text{khi đó: } n > n_0 \Rightarrow | x_n - 0 | = \frac{|a|}{n} < \frac{|a|}{n_0} < \frac{|a|}{\frac{|a|}{\epsilon}} = \epsilon.
$$

# 1.3.2. Tính chất

1) Tính duy nhất

Định lý 1.16. Nếu dãy $(x_n)$ hội tụ đến $A$, thì $A$ là duy nhất.

Chứng minh: Giả sử $(x_n)$ hội tụ đến $A_1$ và hội tụ đến $A_2$ và $A_1 \neq A_2$. Đặt $\epsilon = \frac{1}{2} |A_1 - A_2| > 0.$

Vì $(x_n)$ hội tụ đến $A_1$, theo định nghĩa, tồn tại số $n_1 \in \mathbb{N}$ sao cho $| x_n - A_1 | < \epsilon \forall n \geq n_1 .$

Tương tự, $(x_n)$ hội tụ đến $A_2$, theo định nghĩa, tồn tại số $n_2 \in \mathbb{N}$ sao cho $| x_n - A_2 | < \epsilon ~\forall n \geq n_2.$

Đặt $n_0 = \max \{ n_1 , n_2 \}$, ta có

$$
\left\{
\begin{array}{l}
|x_n - A_1| < \epsilon \\
|x_n - A_2| < \epsilon 
\end{array} \right. ~\forall n \geq n_0,
$$

suy ra $\begin{array}{r}|A_1 - A_2| = |A_1 - x_n + x_n - A_2| \leq |x_n - A_1| + |x_n - A_2| < 2\epsilon = 2.\frac{1}{2} |A_1 - A_2|,\end{array}$ điều này chứng tỏ $A_1 = A_2$. □

2) Tính bị chặn

Định lý $\mathbf{1.17. +}$ Nếu $\lim x_n = A \neq \infty$, thì $(x_n)$ bị chặn.

$+ ~\text{Nếu}~ \lim_{n \to \infty} x_n = +\infty$, thì $(x_n)$ bị chặn dưới.

$+ ~\text{Nếu}~ \lim_{n \to \infty} x_n = -\infty$, thì $(x_n)$ bị chặn trên.

Chứng minh $+$ Giả sử $\lim x_n = A \neq \infty$, theo định nghĩa,

$$
\forall \epsilon > 0, \exists n_0 \in \mathbb{N}, \forall n \geq n_0 \Rightarrow |x_n - A| < \epsilon.
$$

$$
|x_n| = |x_n - A + A| \leq |x_n - A| + |A| < \epsilon + |A| ~\forall n \geq n_0.
$$

Đặt

$$
m = \operatorname*{min} \{ x_0, x_1, . . . , x_{n_0 - 1}, -( \epsilon + | A | ) \},
$$

$$
M = \operatorname*{max} \{ x_0, x_1, . . . , x_{n_0 - 1}, \epsilon + | A | \},
$$

# 1.3.4. Dãy đơn điệu

a) Định nghĩa  
- Dãy số $( x _ { n } )$ được gọi là dãy tăng, nếu $x _ { n } \leq x _ { n + 1 } \forall n$  
- Dãy $( x _ { n } )$ được gọi là dãy giảm, nếu $x _ { n } \geq x _ { n + 1 } \forall n$

b) Tính chất

Định lý 1.27.
-Nếu dãy số $( x _ { n } )$ tăng và bị chặn trên thì tồn tại giới hạn hữu hạn  
$\lim_{n \to \infty} x _ { n }$ (hay dãy $( x _ { n } )$ hội tụ).   
- Nếu dãy $s \boldsymbol { \hat{o}^\prime } ( \boldsymbol{x_n} )$ giảm và bị chặn dưới thì dãy $( x _ { n } )$ hội tụ.

Chứng minh  
Trước hết ta quan tâm đến khái niệm cận trên đúng (supremum) và cận dưới đúng (infimum) của một tập hợp $M \subset \mathbb{R}$:  

-Số $\alpha$ được gọi là cận trên đúng của $M$, ký hiệu $\alpha = \operatorname*{sup} M$, nếu $\alpha$ là số nhỏ nhất thỏa mãn $x \leq \alpha \forall x \in M$

-Số $\beta$ được gọi là cận dưới đúng của $M$, ký hiệu $\beta = \operatorname*{inf} M$, nếu $\beta$ là số lớn nhất thỏa mãn $x \geq \beta \forall x \in M$

Tiền đề  
Nếu $M$ bị chặn dưới thì tồn tại inf $M$, nếu $M$ bị chặn trên thì tồn tại sup $M$:  

-Nếu $( x _ { n } )$ tăng và bị chặn trên, theo tiền đề trên, tồn tại $A = \operatorname*{sup} \{ x _ { n } : n \in \mathbb{N} \}$:  
Với mọi $\epsilon > 0$, tồn tại $n_0$ sao cho  
$$
x_{n_0} > A - \epsilon.
$$

Do $( x _ { n } )$ tăng hay $x _ { n } \leq x _ { n + 1 } \leq \ldots$, nên $x _ { n _ { 0 } } \leq x _ { n } \forall n \geq n _ { 0 }$. Khi đó

$$
x_{n} \geq x_{n_{0}} > A - \epsilon \quad \forall n \geq n_{0}.
$$

Mặt khác, theo định nghĩa của $A$ ta có $x_{n} \leq A < A + \epsilon$. Do đó

$$
A + \epsilon > x_{n} > A - \epsilon \quad \forall n \geq n_{0}.
$$

Vậy $\lim x_{n} = A$.

-Nếu $(x_{n})$ giảm và bị chặn dưới, bằng cách làm tương tự, ta đặt $B = \inf\{x_{n} : n \in \mathbb{N}\}$, ta cũng chứng minh được rằng $\lim x_{n} = B$.

# 1.3.5. Hai dãy $\mathbf{k}\hat{\mathbf{e}}$ nhau

a) Định nghĩa: Hai dãy $(x_n)$ và $(y_n)$ gọi là $\mathbf{k}\hat{\mathbf{e}}$ nhau khi và chỉ khi $(x_n)$ tăng, $(y_n)$ giảm và 
\[
\lim_{n \to \infty} (y_n - x_n) = 0.
\]

b) Tính chất

Định lý 1.31: Nếu hai dãy $(x_n)$ và $(y_n)$ ke nhau, thì cả hai dãy hội tụ cùng điểm.

Chứng minh Gia su hai dãy $(x_n)$ và $\left( y_n \right)$ ke nhau, theo định nghĩa, dãy $z_n = y_n - x_n$ hội tụ về $0$. Do vậy $z_n \ge 0\ \forall n \Leftrightarrow x_n \le y_n$. Kết hợp điều này với $\left( y_n \right)$ giảm, ta có $(x_n)$ tăng và bị chặn trên, dãy $\left( y_n \right)$ giảm và bị chặn dưới. Theo tính chất của dãy đơn điệu, hai dãy $\left(x_n\right)$ và $\left(y_n\right)$ hội tụ. Vì $\lim_{n \to \infty} (y_n - x_n) = 0$, suy ra 
$$
\lim_{n \to \infty} x_n = \lim_{n \to \infty} y_n.
$$

Hè qua (định lý Cantor) Nếu dãy đoạn $\left[ x_n, y_n \right]$ thỏa mãn

$$
\begin{cases}
\left[x_{n+1}, y_{n+1}\right] \subseteq \left[x_n, y_n\right]\ \forall n \\
\lim_{n \to \infty} (y_n - x_n) = 0,
\end{cases}
$$

thì tồn tại duy nhất số $A$ sao cho
$$
\bigcap_{n=0}^{\infty}[x_n, y_n] = \{ A \}.
$$

Chứng minh rằng $[ x _ { n + 1 } , y _ { n + 1 } ] \subseteq [ x _ { n } , y _ { n } ] \forall n$, suy ra $( x _ { n } )$ tăng và $\left( y _ { n } \right)$ giảm. Như vậy, hai dãy $( x _ { n } )$ và $( y _ { n } )$ kẹp nhau. Theo định lý trên, tồn tại duy nhất $A$ sao cho $\lim_{n \to \infty} x _ { n } = \lim_{n \to \infty} y _ { n } = A .$ □

Ví dụ 1.32. Chứng minh rằng $( x _ { n } )$ và $( y _ { n } )$ kẹp nhau, với

$$
x _ { n } = \sum _ { k = 3 } ^ { n } { \frac { 1 } { 1 + k ^ { 2 } } } , y _ { n } = x _ { n } + { \frac { 1 } { n } } - { \frac { 1 } { 2 n ^ { 2 } } } \quad (n \geq 3).
$$

Chứng minh: Theo giả thiết $x _ { n } = \sum _ { k = 3 } ^ { n } { \frac { 1 } { 1 + k ^ { 2 } } }$, ta có

$$
x _ { n + 1 } - x _ { n } = { \frac { 1 } { ( n + 1 ) ^ { 2 } + 1 } } \geq 0 \quad \forall n \geq 3,
$$

vậy dãy số $( x _ { n } )$ tăng.

Theo giả thiết $x _ { n } = \sum _ { k = 3 } ^ { n } { \frac { 1 } { 1 + k ^ { 2 } } }, y _ { n } = x _ { n } + { \frac { 1 } { n } } - { \frac { 1 } { 2 n ^ { 2 } } } \quad (n \geq 3)$, ta có

$$
\begin{array} { c } { y _ { n + 1 } - y _ { n } = ( x _ { n + 1 } - x _ { n } ) + \displaystyle \frac { 1 } { n + 1 } - \displaystyle \frac { 1 } { n } - \displaystyle \frac { 1 } { 2 ( n + 1 ) ^ { 2 } } + \displaystyle \frac { 1 } { 2 n ^ { 2 } } } \\ { = \displaystyle \frac { - ( n - 1 ) ^ { 2 } + 3 } { 2 n ^ { 2 } ( n + 1 ) ^ { 2 } ( n ^ { 2 } + 2 n + 2 ) } } \\ { \leq 0 \forall n \geq 3 , } \end{array}
$$

Vậy đây $( y _ { n } )$ là dãy giảm.

Theo giả thiết $y _ { n } = x _ { n } + \frac { 1 } { n } - \frac { 1 } { 2 n ^ { 2 } } \quad n \geq 3 ,$

$$
\lim_{n \to \infty} \left( y _ { n } - x _ { n } \right) = \lim_{n \to \infty} \left( \frac { 1 } { n } - \frac { 1 } { 2 n ^ { 2 } } \right) = 0 .
$$

Theo định nghĩa, hai dãy $\left( x _ { n } \right)$ và $( y _ { n } )$ kề nhau.

# 1.3.6. Dãy con

a) Định nghĩa Cho một dãy số $( x _ { n } )$. Dãy $( x _ { n _ { k } } )$ được gọi là dãy con của dãy $( x _ { n } )$, nếu

$$
n _ { 1 } < n _ { 2 } < \ldots < n _ { k } < \ldots
$$

b) Các tính chất

+ Tính chất I Nếu dãy $( x _ { n } )$ hội tụ đến $x ^ { * }$, thì mọi dãy con $( x _ { n _ { k } } )$ của nó cũng hội tụ đến $x ^ { * }$:

Chứng minh Theo giả thiết $\lim_{n \to \infty} x _ { n } = x ^ { * }$, theo định nghĩa,

Chọn $k_{0}$ thỏa mãn $n_{k_{0}} \geq n_{0}$, ta có $n_{k} \geq n_{0} \forall k \geq k_{0}$. Vậy

Điều đó có nghĩa là $\lim _{k \to \infty} x_{n_{k}} = x^{*}$.

$+$ Tính chất 2: Dãy $(x_{n})$ hội tụ đến $x^{*}$ khi và chỉ khi hai dãy con $\left(x_{2n}\right)$ và $\left(x_{2n+1}\right)$ đều hội tụ đến $x^{*}$:

Chứng minh $(\Rightarrow)$: Hiện nhiên theo tính chất 1.

$(\Leftarrow)$ Giả thiết cho mỗi $\lim _{k \to \infty} x_{2k} = x^{*} = \lim _{k \to \infty} x_{2k+1}$, theo định nghĩa, tồn tại $k_{1}, k_{2}$ sao cho

$$
\left\{
\begin{array}{l}
|x_{2k} - x^{*}| < \epsilon ~ \forall k \geq k_{1} \\
|x_{2k+1} - x^{*}| < \epsilon ~ \forall k \geq k_{2}.
\end{array}
\right.
$$

Đặt $n_{0} = \max \{2k_{1}, 2k_{2} + 1\}$. Khi đó,

$$
\forall n \geq n_{0} \Rightarrow 
\left\{
\begin{array}{ll}
n \geq 2k_{1} \\
n \geq 2k_{2} + 1.
\end{array}
\right.
$$

-Nếu $n$ có dạng $n = 2k$ với $\boldsymbol{k} \in \mathbb{N}$, thì $k \geq k_1 \Rightarrow |x_n - x^*| = |x_{2k} - x^*| < \epsilon.$

-Nếu $n$ có dạng $n = 2k + 1$ với $k \in \mathbb{N}$, thì $k \geq k_2 \Rightarrow |x_n - x^*| = |x_{2k+1} - x^*| < \epsilon.$ Như vậy, với mọi $n \geq n_0$, ta có $\left| x_n - x^* \right| < \epsilon$ hay $\lim_{n \to \infty} x_n = x^*.$

Ví dụ 1.33. Cho dãy $(x_n)$ thỏa mãn

$$
0 \leq x_{n+m} \leq \frac{n + m}{nm}.
$$

Chứng minh rằng $\lim_{k \to \infty} x_n = 0$

Thay $m = n$ ta có

$$
0 \leq x_{2n} \leq \frac{2n}{n^2} \Rightarrow \lim_{k \to \infty} x_{2n} = 0.
$$

Thay $m = n + 1$ ta có

$$
0 \leq x_{2n+1} \leq \frac{n + (n + 1)}{n(n + 1)} \Rightarrow \lim_{k \to \infty} x_{2n+1} = 0.
$$

Theo tính chất trên, $\lim_{k \to \infty} x_n = 0$

+ Tính chất 3 (định lý Bolzano-Weierstrass)

Từ mọi dãy bị chặn ta đều có thể rút ra một dãy con hội tụ.

Chứng minh (phương pháp chia đôi)

Cho $( x _ { n } )$ là một dãy bị chặn. Ta sẽ xây dựng bằng quy nạp hai dãy $\mathbf{k}$ nghịch với nhau $( a _ { k } ), ( b _ { k } )$ và dãy con $( x _ { n _ { k } } )$ sao cho $x _ { n _ { k } } \in [ a _ { k } ; b _ { k } ] \forall k \ge 1 .$

Vì $( x _ { n } )$ bị chặn nên tồn tại $a _ { 0 }$ và $b _ { 0 }$ sao cho $a _ { 0 } \leq x _ { n } \leq b _ { 0 } \forall n$ .

Bước $I$. Chia $[ a _ { 0 } ; b _ { 0 } ]$ thành hai đoạn $\left[ a _ { 0 } ; \frac { a _ { 0 } + b _ { 0 } } { 2 } \right]$ và $\left[ \frac { a _ { 0 } + b _ { 0 } } { 2 } ; b _ { 0 } \right]$. Xảy ra hai trường hợp:
- Nếu $\left[ a _ { 0 } ; \frac { a _ { 0 } + b _ { 0 } } { 2 } \right]$ chứa vô hạn phần tử của dãy $( x _ { n } )$, thì đặt $a _ { 1 } = a _ { 0 }, b _ { 1 } = \frac { a _ { 0 } + b _ { 0 } } { 2 }$ và chọn $x _ { n _ { 1 } } \in [ a _ { 1 } ; b _ { 1 } ]$:

- Nếu $\left[ \frac { a _ { 0 } + b _ { 0 } } { 2 } ; b _ { 0 } \right]$ chứa vô hạn phần tử của dãy $( x _ { n } )$, thì đặt $a _ { 1 } = \frac { a _ { 0 } + b _ { 0 } } { 2 }, b _ { 1 } = b _ { 0 }$ và chọn $x _ { n _ { 1 } } \in [ a _ { 1 } ; b _ { 1 } ]$.

Sau bước 1, ta có

$$
\left\{ \begin{array} { l l }
{ [ a _ { 1 } ; b _ { 1 } ] \subset [ a _ { 0 } ; b _ { 0 } ] } \\
{ b _ { 1 } - a _ { 1 } = \frac{1}{2} ( b _ { 0 } - a _ { 0 } ) } \\
{ [ a _ { 1 } ; b _ { 1 } ] \subset \mathrm{h} \tilde{\mathrm{u}} \mathrm{~x} \hat{\mathrm{o}} \mathrm{~hán ~p} \hat{\mathrm{a}n ~t} \tilde{\mathrm{i}} \mathrm{c} \tilde{\mathrm{u}} \mathrm{~d} \tilde{\mathrm{a}} \mathrm{~d} \tilde{\mathrm{a}} \mathrm{y ~( x _ { n } ) } } \\
{ \exists x _ { n _ { 1 } } \in [ a _ { 1 } ; b _ { 1 } ] }
\end{array} \right.
$$

Bước $k$ Chia $[ a _ { k - 1 } ; b _ { k - 1 } ]$ thành hai $\scriptstyle { \left[ a _ { k - 1 } ; { \frac { a _ { k - 1 } + b _ { k - 1 } } { 2 } } \right] }$ và $\textstyle { \left[ { \frac { a _ { k - 1 } + b _ { k - 1 } } { 2 } } ; b _ { k - 1 } \right] }$. Xét ra hai trường hợp:

- Nếu $\scriptstyle { \left[ a _ { k - 1 } ; { \frac { a _ { k - 1 } + b _ { k - 1 } } { 2 } } \right] }$ chưa vô hạn phần tử của dãy $( x _ { n } )$, thì đặt $a _ { k } = a _ { k - 1 } , b _ { k } = \frac{a_{k-1} + b_{k-1}}{2}$ và chọn $x_{n_k} ∈ [a_k; b_k]$ sao cho $n_k > n_{k-1}$.

- Nếu $\textstyle { \left[ { \frac { a _ { k - 1 } + b _ { k - 1 } } { 2 } } ; b _ { k - 1 } \right] }$ chưa vô hạn phần tử của dãy $( x _ { n } )$, thì đặt $\begin{array} { r }
{ a _ { k } = \frac { a _ { k - 1 } + b _ { k - 1 } } { 2 } }
\end{array}$, $b _ { k } = b _ { k - 1 }$ và chọn $x _ { n _ { k } } \in [ a _ { k } ; b _ { k } ]$ sao cho $n _ { k } > n _ { k - 1 }$.
